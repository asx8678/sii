### Goal
Make "Si beats a single session" measurable: numeric targets checked against eval runs, and a first suite of 20 real tasks.

### Deliverables
- Settings `evals.targets` (schema + defaults), `si eval targets <evr_id>`; `evals/seed/**` (20 tasks); tests for the targets check.

### Specification
Targets (defaults; compared against the single-session arm on the same tasks):

| Key | Meaning | Default |
|---|---|---|
| `pass_rate_delta_pp` | Si pass rate minus single, percentage points, lower CI bound | ≥ 15 |
| `cost_ratio` | Si cost / single cost, upper CI bound | ≤ 2.5 |
| `quick_time_ratio` | Si median time / single median time (quick tier) | ≤ 2.0 |
| `interventions_per_run` | your interventions per Si run | ≤ 1 |
| `canary_catch_rate` | reviewer canary catch rate (from M12; skipped until then) | ≥ 0.8 |
| `flaky_check_rate` | checks that change result on an identical snapshot re-run | ≤ 0.02 |

`si eval targets <evr_id>` prints `TARGET · VALUE · CI · MET` and exits 0 only when all available targets are met.

Seed suite: by default from `/Users/adam2/projects/pair/pi-fovea` and `/Users/adam2/projects/pair/pi-fabric` history (TypeScript + vitest; confirm with the owner — this is an open question in the blueprint). Choose commits that add or change behavior together with tests, change fewer than 300 lines, and pass `si eval task new` validation. Aim for a mix: 8 small fixes, 8 features, 4 refactors with tests.

### Tests
Targets computation on fixture results (met, not met, CI straddling the threshold → not met).

### Acceptance criteria
1. 20 validated tasks under `evals/seed/`.
2. Manual, with real models: `si eval run seed --arms single,si_quick --repeat 1` completes and `si eval targets` prints a table. Record the output in the completion note (the targets need not be met yet; this establishes the baseline).
