### Goal
Score each run with the hidden tests, repeat runs, compare arms with confidence intervals, and write a report.

### Deliverables
- Migrations `create_eval_runs`, `create_eval_results`; `lib/si/evals/scoring.ex`, `lib/si/evals/stats.ex`, `lib/si/evals/report.ex`; CLI `si eval run`, `si eval report`; tests.

### Specification
- Scoring: in the workdir at `final_sha`, `git apply hidden_tests.patch` (failure to apply → not passed, reason `hidden tests do not apply`), run `test_command` with the task timeout → `passed = exit 0`.
- `si eval run <suite> [--arms single,si_quick] [--repeat 3] [--tasks a,b]`: creates an `eval_runs` row; for every task × arm × repeat: `Arms.run/4`, score, insert `eval_results` (`passed`, `cost_usd`, `duration_ms`, `interventions`, `review_rounds`, `error`); runs sequentially by default (`--parallel N` optional, bounded by the scheduler).
- Stats (`Si.Evals.Stats`, pure):
  - Per arm: pass rate, mean cost, median duration, interventions per run.
  - Paired per task (value = mean over repeats): difference of pass rates (Si − single) and ratio of costs; 95% bootstrap CI with 10,000 resamples over tasks, seeded (`:rand.seed(:exsss, seed)`) for reproducibility.
- Report: `$SI_HOME/evals/<evr_id>/report.md` and `report.json` with a summary table, per-task rows, CIs and the settings used; `si eval report <evr_id>` prints it.

### Tests
Stats functions on fixed data (known pass rates and CIs with a fixed seed; golden values); scoring with fixture workdirs (tests pass / fail / patch does not apply); CLI run with a faux 2-task suite.

### Acceptance criteria
Tests pass; `bin/ci` passes.
