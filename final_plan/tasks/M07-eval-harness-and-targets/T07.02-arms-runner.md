### Goal
Run one eval task in one arm, isolated from your real repositories, and collect the final code state, cost, time, interventions and review rounds.

### Deliverables
- `lib/si/evals/arms.ex` (`Si.Evals.Arms`), `priv/prompts/eval/single.md`; tests `test/si/evals/arms_test.exs` (`@tag :pi`).

### Specification
```elixir
@spec run(Si.Evals.TaskSpec.t(), :single | :si_quick | {:si_without, atom()}, pos_integer(), keyword()) ::
        {:ok, %{final_sha: String.t(), cost_usd: float(), duration_ms: integer(), interventions: integer(), review_rounds: integer(), workdir: Path.t()}} | {:error, term()}
#   opts: eval_run_id, model (builder model; default settings), timeout_s
```
- Workdir: `git clone --local <repo> $SI_HOME/evals/<eval_run_id>/<task>/<arm>-<repeat>`, checkout `base_commit`, copy the eval task's `repo.yml` into the clone as `.si/repo.yml` when the clone has no profile.
- `:single`: start one session with profile `eval_single` (Fabric + Fovea + bridge in observe mode) and the builder model, `run_id = eval_run_id`, prompt from `priv/prompts/eval/single.md` (version 1: `Implement the following. Run the tests with <test command pattern> before you finish. Stop when done.` + instructions). Wait for idle (with the timeout); freeze the working tree → `final_sha` (snapshot commit).
- `:si_quick`: register the clone as a Si repo (integration branch at `base_commit`), create a task (tier quick, description = instructions, `run_id = eval_run_id`), let the normal dispatcher and loop run it; wait until `landed`, `escalated`, `failed`, or the timeout; `final_sha` = the integration head. Inbox items created for this task are counted as interventions and resolved with their recommendation after 60 s (eval mode: settings `evals.auto_resolve_s`), so runs don't stall.
- `{:si_without, feature}` (ablations used by T07.04 and later): the same as `:si_quick` with one feature disabled through a per-run override map: `:review` (skip Astra; approve after checks), `:astra_fix` (fix policy writer), `:checks_extra` (only build and tests). The override is stored on the task and read by the loop.
- Cost: sum of `model_calls.cost_usd` for sessions with `run_id = eval_run_id` and this task/arm (tag the sessions with an `eval_arm` env and store it in the session row's `versions` map, or add a column).
- Cleanup: stop sessions; keep the workdir until scoring (T07.03) finishes.

### Tests
(`@tag :pi`, faux) A two-file fixture repo and task: the `:single` arm with a faux script that writes the solution; the `:si_quick` arm with faux builder + faux Astra approving → `final_sha` contains the solution in both; interventions counted when a faux Astra escalates.

### Acceptance criteria
Tests pass with `--include pi`; `bin/ci` passes.

### Verify


**Expected result.**
- `Si.Evals.Arms.run/4` runs one task in one arm, in a clone under `$SI_HOME/evals/<run>/…`:
  - the single-session arm;
  - the quick arm, using Si's normal dispatcher and loop;
  - ablations, through per-run overrides.
- It collects the final SHA, cost, time, interventions and review rounds.

**Checks**
1. `mix test test/si/evals/arms_test.exs --include pi --repeat-until-failure 3`.
   Expected: every run passes.
2. The workdir location.
   Expected: under `$SI_HOME/evals/`. The source repository is unchanged, as in T07.01's check 1.
3. Interventions in eval mode.
   Expected: counted, and resolved automatically only when `evals.auto_resolve_s` applies. Normal runs are never auto-resolved.
4. Cost attribution.
   Expected: only the sessions of this run and arm are counted.

**Redo if**
- Ablations are done with global settings changes instead of per-run overrides. Rewrite them: other runs must be unaffected.
