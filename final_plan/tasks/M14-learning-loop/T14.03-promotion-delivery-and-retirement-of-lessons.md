### Goal
Lessons that keep applying become guidance for their model family, delivered in a cache-friendly way, and retire when they don't reduce the failure rate.

### Deliverables
`lib/si/learning/lessons.ex`; generated files `$SI_HOME/profiles/_lessons/<family>.md`; session start adds `--append-system-prompt <that file>` for the session's model family; CLI `si lessons list|show|edit|retire`; cockpit Lessons page; tests.

### Specification
- Promotion: `hint → guidance` when occurrences ≥ 3 distinct sessions; record `rate_before` (failures of the fingerprint per 1,000 execs, or per 100 reviews for findings, over the previous 7 days).
- Delivery: the family file lists active guidance lessons (max 20, ordered by promotion time, stable), regenerated only when the set changes; it is read at session start only, so a running session's prompt prefix never changes (prompt cache friendly).
- Retirement: after 100 more execs (or 30 reviews) for that family, compute `rate_after`; retire if it did not drop by at least 30%.
- You can edit a lesson's text (`si lessons edit <id>` opens `$EDITOR` through the CLI's local side and sends the new text) or retire it.

### Tests
Promotion threshold; file regeneration only on change; retirement rule; a new session gets the append flag for its family.

### Acceptance criteria

**Expected result.**
- Lessons that keep applying are promoted to guidance and delivered through a per-family file. The file is read only at session start, so running prompts never change.
- A lesson is retired when it does not cut the failure rate by 30%.

**Checks**
1. The per-family file's modification time after repeated runs with an unchanged set of lessons.
   Expected: unchanged. The file is regenerated only when the set changes.
2. A new session for that family.
   Expected: its launch arguments include `--append-system-prompt <family file>`; running sessions' arguments are unchanged.
3. The retirement rule on fixture rates.
   Expected: a drop of less than 30% retires the lesson.

**Redo if**
- Lessons are added to running sessions, which breaks their prompt cache. Deliver them only at session start.
