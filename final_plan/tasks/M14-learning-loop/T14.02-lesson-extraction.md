### Goal
Turn resolved, repeated failures into short candidate lessons per model family.

### Deliverables
Migration `create_lessons` (`id`, `family`, `fingerprint`, `text`, `status` (`hint|guidance|retired`), `occurrences`, `rate_before`, `rate_after`, `prompt_version`, timestamps); `lib/si/learning/extract.ex`; settings `models.lessons` (a cheap model); tests with `Req.Test`.

### Specification
- For each fingerprint with at least one resolution and no lesson for that family: collect up to 3 examples (the failure detail and what the next successful attempt did differently: for code mode, the successful exec's operations summary; for findings, the fixing diff hunk).
- One ReqLLM call with a structured output `{lesson: "When <situation>, do <this> instead of <that>." (≤ 200 characters), confidence}`; confidence < 0.5 → discard.
- Insert with `status: hint`, `occurrences` = distinct sessions with the fingerprint.

### Tests
Stubbed model responses create lessons; duplicates per family/fingerprint prevented; low confidence discarded.

### Acceptance criteria
Tests pass; `bin/ci` passes.

### Verify
```bash
mix test test/si/learning/extract_test.exs
```

**Expected result.** For each resolved, repeated failure fingerprint, one structured model call writes at most one candidate lesson per family. Lessons with confidence below 0.5 are discarded.

**Checks**
1. Stubbed responses.
   Expected: lessons of at most 200 characters, in the form "When …, do … instead of …".
2. The same fingerprint and family processed twice.
   Expected: one lesson.
3. Confidence 0.4.
   Expected: no lesson.

**Redo if**
- More than 3 examples go into the prompt, or examples contain transcripts. Bound them as specified.
