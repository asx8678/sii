### Goal
Implement the four command-based checks, including the rules for which tests to run.

### Deliverables
- `lib/si/checks/format.ex`, `build.ex`, `lint.ex`, `tests.ex` (modules `Si.Checks.Format`, `Si.Checks.Build`, `Si.Checks.Lint`, `Si.Checks.Tests`), registered in the default registry.
- Tests `test/si/checks/basic_checks_test.exs`, `test/si/checks/test_selection_test.exs`.

### Specification
All four: if the profile has no command for them → `:skipped` with `reason: "no command"`. Pass iff exit status 0. Timeouts from `checks.timeouts_s.<name>` (tests uses `tests`; running `test_all` uses `test_all`). Logs at `Si.Paths.check_log(snapshot.id, name)`.

- **format**: `format` command with `{files}` = changed, non-deleted files; if the template has `{files}` and the list is empty → `:skipped` (`reason: "no files"`).
- **build**: `build` command; placeholders not expected.
- **lint**: `lint` command with `{files}` = changed, non-deleted files that are not binary; empty → `:skipped`.
- **tests**: `test` command with `{tests}` = `select/1`; if the selection is empty, run `test_all` (details `selection: "all"`).

Test selection (`Si.Checks.Tests.select(ctx) :: {[String.t()], reason :: String.t()}`), first non-empty rule wins:
1. `task.test_paths` (glob-expanded against the slot's files) → reason `"task"`.
2. Changed files that match `tests.patterns` → reason `"changed tests"`, plus rule 3's matches.
3. For each changed source file, conventional test files that exist in the slot:
   - Elixir: `lib/<path>.ex` → `test/<path>_test.exs`.
   - TypeScript/JavaScript: `src/<dir>/<name>.<ext>` → files matching `**/<name>.test.<ext>` or `**/<name>.spec.<ext>` (ext in ts, tsx, js, mjs).
   → reason `"conventional"`.
4. Empty → run `test_all` → reason `"all"`.
(M10 adds a Fovea-impact rule between 2 and 3.)

Details recorded: `%{"selection" => [...], "reason" => reason}` for tests; `%{"files" => n}` for format/lint.

### Tests
- Each check: pass, fail and skipped (no command) with fixture repos.
- format/lint receive only changed, existing files (assert via a command that writes its args to a file).
- Selection rules 1–4 with fixture trees for Elixir and TypeScript layouts.

### Acceptance criteria
Tests pass; `bin/ci` passes.

### Verify
```bash
mix test test/si/checks/basic_checks_test.exs test/si/checks/test_selection_test.exs
```

**Expected result.**
- The four command checks (format, build, lint, tests) behave as specified: skip rules, pass by exit status, per-check timeouts and logs.
- Test selection applies rules 1–4, first match wins, and records the reason.

**Checks**
1. Elixir fixture: change `lib/a/b.ex` while `test/a/b_test.exs` exists.
   Expected: `select/1` returns `{["test/a/b_test.exs"], "conventional"}`.
2. TypeScript fixture: change `src/x/y.ts` while `test/y.test.ts` exists.
   Expected: the test file is selected with reason `conventional`.
3. Use a format command that writes its arguments to a file, with a deleted file among the changes.
   Expected: the deleted file is not in the arguments.
4. Set `checks.timeouts_s.tests: 1` and use a command that sleeps 5 s.
   Expected: `:fail` with `timed_out: true` after about 1 s.
5. Remove every conventional test, with no pattern matches.
   Expected: `test_all` runs, with reason `all`.

**Redo if**
- Selection is hard-coded to one language or one layout. Rewrite it per the four rules.
