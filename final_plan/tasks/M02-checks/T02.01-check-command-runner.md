### Goal
Run a repo-profile command in a leased check slot with placeholders expanded safely, output captured to a log, a hard timeout that kills the whole process tree, and a structured result.

### Context
`05-schemas-and-config.md` §2 (placeholders), `01-architecture.md` §4 (MuonTrap is used for check commands).

### Deliverables
- `lib/si/checks/command.ex` (`Si.Checks.Command`), `lib/si/checks/command_result.ex` (struct).
- Tests `test/si/checks/command_test.exs`.

### Specification
```elixir
@type vars :: %{optional(:files) => [String.t()], optional(:tests) => [String.t()], optional(:lcov) => String.t()}
@spec expand(String.t(), vars(), Si.Checks.Slot.t()) :: {:ok, String.t()} | {:empty, atom()}
@spec run(Si.Checks.Slot.t(), String.t(), vars(), keyword()) :: CommandResult.t()
#   opts: timeout_ms (required), log_path (required), check (atom, for logging)
```
`%CommandResult{command, exit_status (integer | nil), timed_out (boolean), duration_ms, log_path, output_tail (last 8 KiB as a UTF-8-safe string)}`.

Expansion rules:
- `{files}` and `{tests}` expand to the list, each element shell-quoted with single quotes (`'` inside becomes `'\''`), joined by spaces. If the list is empty, `expand/3` returns `{:empty, :files}` / `{:empty, :tests}`; the caller decides whether to skip or to run without the placeholder (`expand_without/2` removes the placeholder token).
- `{lcov}` expands to the quoted path; `{slot}` to the partition number; `{port}` to the slot's `port_base`.
- Unknown `{name}` placeholders are left untouched and logged once as a warning.

Execution:
- `MuonTrap.cmd("/bin/sh", ["-c", command], cd: slot.path, env: env, stderr_to_stdout: true, into: <collectable writing to log_path>, timeout: timeout_ms, delay_to_sigkill: 5_000)`.
- `env`: the slot's `env` plus `CI=1`, `NO_COLOR=1`, `FORCE_COLOR=0`, `TERM=dumb`.
- The log starts with a header line `$ <command>` and ends with `# exit <status> in <ms> ms` (or `# timed out after <ms> ms`).
- Log size: stream to the file; after completion, if the file exceeds 2 MiB, rewrite it keeping the header, a line `# ... <n> bytes omitted ...`, and the last 2 MiB.

### Tests
- `expand/3`: quoting of names with spaces and quotes; empty lists give `{:empty, :files}`; `{slot}`/`{port}` substitution.
- `run/4`: output lands in the log with the header and footer; exit status 0 and 3 reported correctly; env variables from the slot are visible (`echo $MIX_TEST_PARTITION`).
- Timeout: `sh -c 'sleep 30 & sleep 30 & wait'` with a 300 ms timeout returns `timed_out: true` within 7 s, and `pgrep -f 'sleep 30'` finds no process started by the test afterwards (use a unique marker like `sleep 30.123`).
- Truncation: a command printing 3 MiB (`head -c 3145728 /dev/zero | tr '\0' 'a'`) leaves a log ≤ 2 MiB + header, containing the omission line.

### Acceptance criteria
Tests pass; `bin/ci` passes.

**Expected result.**
- `expand/3` quotes `{files}` and `{tests}` safely, and substitutes `{slot}`, `{port}` and `{lcov}`.
- `run/4` runs the command in the leased slot through MuonTrap and streams output to a log with a header and a footer.
- The timeout kills the whole process tree, and logs over 2 MiB are truncated with an omission line.

**Checks**
1. `expand("echo {files}", %{files: ["a b", "it's"]}, slot)` in a test or `mix run`.
   Expected: `{:ok, "echo 'a b' 'it'\\''s'"}`, and the shell prints `a b` and `it's` as two arguments.
2. After the timeout test: `pgrep -f 'sleep 30.123'`.
   Expected: no process.
3. `head -1` and `tail -1` of a log from a passing command.
   Expected: `$ <command>`, then `# exit 0 in <n> ms`.
4. The 3 MiB output test's log.
   Expected: size ≤ 2 MiB plus the header line, and it contains `# ... <n> bytes omitted ...`.
5. A command that runs `env`.
   Expected: the output contains `CI=1`, `NO_COLOR=1`, `FORCE_COLOR=0`, `TERM=dumb` and the slot's variables.
6. `grep -nE 'delay_to_sigkill|timeout' deps/muontrap/lib/muontrap.ex`.
   Expected: both options are documented in the installed MuonTrap.

**Redo if**
- `sleep` processes survive the timeout on macOS. MuonTrap is then not killing the process group. Don't work around it with `pkill`. Set the task to `blocked`, with the `pgrep` evidence: the runner design is the owner's question.
- Output is collected in memory instead of streamed to the log. Rewrite it with the collectable.
