### Goal
Fail a change that touches files outside its task's scope (plus approved scope requests), and always fail changes to risky paths that are not explicitly in scope.

### Deliverables
- `lib/si/glob.ex` (`Si.Glob`), `lib/si/checks/scope.ex` (`Si.Checks.Scope`), tests `test/si/glob_test.exs`, `test/si/checks/scope_test.exs`.

### Specification
`Si.Glob.match?(pattern, path)` and `Si.Glob.compile(pattern) :: Regex.t()`: supports `**` (any number of path segments, including zero), `*` (within a segment), `?`, `[abc]`, and `{a,b}` alternation; paths use `/`; matching is anchored at both ends. Patterns ending in `/` match everything below.

`Si.Checks.Scope.run(ctx)`:
- No task, or `task.scope == []` → `:skipped` (`reason: "no scope"`).
- `allowed = task.scope ++ task.approved_scope`.
- For each changed file (use the new path for renames; also check the old path for deletions): outside `allowed` → finding `outside_scope`; matches a `risky_paths` glob and is not matched by a pattern in `task.scope`/`approved_scope` that names it explicitly (a pattern without wildcards, or one of the approved request's exact files) → finding `risky_path`.
- `:fail` when any finding exists. Details: `%{"outside_scope" => [...], "risky" => [...]}`.

### Tests
Glob: `src/**/*.ts` matches `src/a.ts` and `src/a/b/c.ts`; `**/test/*.exs` matches `test/x.exs`; `{lib,test}/**` alternation; `?` and character classes; property test: for random segment lists, `a/**/z` matches iff the path starts with `a/` and ends with `/z`.
Scope: pass within scope; fail outside; approved request allows the extra file; a risky path in a broad `**` scope fails, but passes when the exact file is listed.

### Acceptance criteria
Tests pass; `bin/ci` passes.

**Expected result.**
- `Si.Glob` matches `**`, `*`, `?`, `[abc]` and `{a,b}`, anchored at both ends, with a trailing `/` meaning "everything below".
- The scope check fails files outside the task's scope (plus approved requests), and risky paths unless they are listed exactly.

**Checks**
1. Glob cases. Expected:
   - `**/x` matches `x` and `a/b/x`;
   - `a/**` matches `a/b/c`;
   - `{lib,test}/**/*.ex` matches `lib/a.ex` and `test/b/c.ex`;
   - `docs/` matches `docs/a/b.md`;
   - `a.b` does not match `aXb`.
2. A rename whose old path lies outside the scope, with the file deleted there.
   Expected: the old path is reported.
3. A risky path under a broad `**` scope, then the same path listed exactly.
   Expected: `risky_path` fails, then passes.

**Redo if**
- Patterns become regexes without escaping `.`, `+`, `(`, `)`, `^` or `$`. Rewrite the compiler with escaping.
