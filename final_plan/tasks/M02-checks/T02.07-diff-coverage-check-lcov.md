### Goal
Measure line coverage of the changed lines only and fail below the threshold (default 80%).

### Deliverables
- `lib/si/lcov.ex` (`Si.Lcov`), `lib/si/checks/diff_coverage.ex` (`Si.Checks.DiffCoverage`).
- Si's own `mix.exs`: add `{:lcov_ex, "~> 0.3.6", only: :test, runtime: false}` and `test_coverage: [tool: LcovEx, output: "cover"]` (check the output file name lcov_ex produces and use it in Si's profile later).
- Tests `test/si/lcov_test.exs`, `test/si/checks/diff_coverage_test.exs`, fixture `.info` files.

### Specification
`Si.Lcov.parse(binary) :: %{String.t() => %{pos_integer() => non_neg_integer()}}` from `SF:` / `DA:<line>,<hits>` / `end_of_record`; ignore other record types. `SF` paths are made relative to the slot root when they are absolute and inside it.

Check:
1. No `coverage` command → `:skipped`.
2. Source files considered: changed, non-deleted, non-test, non-binary files.
3. None → `:pass` with note `no source changes`.
4. Run `coverage` with `{tests}` = `Si.Checks.Tests.select/1` and `{lcov}` = the configured path; exit non-zero → `:fail` (`reason: "coverage command failed"`).
5. Parse `<slot>/<coverage.lcov_path>`; missing file → `:error`.
6. For each considered changed line that has a `DA` entry: executable; covered when hits > 0. Lines without `DA` entries are not executable and ignored.
7. `percent = covered / executable * 100` (1 decimal); executable = 0 → `:pass` (`note: "no executable changed lines"`).
8. `:fail` when `percent < settings checks.thresholds.diff_coverage`.
Details: `%{"percent", "covered", "executable", "uncovered" => %{file => [lines]}}` (at most 50 lines total).

### Tests
Parser on sample LCOV (multiple files, absolute and relative SF paths); computation with a fixture diff and LCOV (100%, 50%, no executable lines); end-to-end with a fixture repo whose `coverage` command is `cp coverage.fixture.info coverage/lcov.info`.

### Acceptance criteria
Tests pass; `bin/ci` passes; `mix test --cover` in Si's repo produces an LCOV file.

### Verify
```bash
mix test test/si/lcov_test.exs test/si/checks/diff_coverage_test.exs

```
