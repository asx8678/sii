### Goal
One list of everything that waits on you (escalations, questions, approvals), with CLI access, desktop notifications, wait policies, and a session dialog handler that routes headless dialogs here.

### Context
`03-data-model.md` (`inbox_items`, §3.6).

### Deliverables

- `lib/si/sessions/ui_handler/inbox.ex` (`Si.Sessions.UiHandler.Inbox`), made the default dialog handler.
- CLI `lib/si/cli/commands/inbox.ex`.
- Tests `test/si/inbox_test.exs`, `test/si/sessions/ui_handler_inbox_test.exs`.

### Specification
```elixir
@spec create(map()) :: {:ok, Item.t()}      # kind, title, body, ref_kind, ref_id, recommended, options, wait_policy (default "wait"), default_after_s
@spec list(keyword()) :: [Item.t()]          # status (default open), kind
@spec get(String.t()) :: Item.t() | nil
@spec resolve(String.t(), map(), String.t()) :: {:ok, Item.t()} | {:error, :not_open}   # resolution %{"action" => ..., "note" => ...}, actor
@spec subscribe() :: :ok                      # topic "inbox"
```
- Events `inbox.created` / `inbox.resolved`; broadcasts `{:inbox_created, item}` / `{:inbox_resolved, item}`.
- `wait_policy: "default_after"`: an `Si.Inbox` timer resolves the item with `recommended` after `default_after_s` (actor `timeout`), unless resolved earlier; timers are rebuilt at boot from open items.
- `Si.Notify.desktop(title, body)`: on macOS and when `notifications.desktop` is true, run `osascript -e 'display notification "<body>" with title "Si: <title>"'` (escape quotes); never in tests (`Application.get_env(:si, :notify, true)`).
- Dialog handler: for a session dialog request, create an item `kind: "question"` with the dialog title/message and options (`select` → its options; `confirm` → `["yes", "no"]`; `input`/`editor` → free text via `note`), `ref_kind: "session"`, and `wait_policy: "default_after"` with `default_after_s = timeout/1000` when the dialog has a timeout. Return `:defer`; when the item is resolved, send the answer to the controller, which writes the `extension_ui_response` (`value` or `cancelled: true` for `no`/timeout).
- CLI: `si inbox` (list: ID · KIND · AGE · TITLE), `si inbox show <id>` (body, recommended, options), `si inbox resolve <id> <action> [--note TEXT]`.
