### Goal
Know each model's family so Si can enforce that Astra reviews on a different family than the writer, and pick a fallback when it can't.

### Context
`05-schemas-and-config.md` §6 (catalog format and diversity levels).

### Deliverables
- `priv/models.yml` (the entries from `05` §6), `lib/si/models/catalog.ex` (`Si.Models.Catalog`), `lib/si/models.ex` (`Si.Models` facade), tests `test/si/models/catalog_test.exs`.

### Specification
```elixir
@spec family(String.t()) :: String.t()                           # "provider/model" → family ("unknown" if no match)
@spec diversity(String.t() | nil, String.t()) :: :other_family | :same_family | :same_model_fresh | :no_writer
@spec pick_reviewer(String.t() | nil, [String.t()]) :: {:ok, String.t(), atom()} | {:error, :no_candidates}
```
- Catalog: entries from `priv/models.yml`, then `$SI_HOME/models.yml` entries prepended (yours win). Glob matching with `Si.Glob` (T02.06 may not exist yet on the Astra path: implement a minimal `*` glob here in `Si.Models.Catalog` and switch to `Si.Glob` later if you prefer).
- `diversity/2`: writer nil → `:no_writer`; different families and neither `unknown` → `:other_family`; same family, different model → `:same_family`; same model → `:same_model_fresh`; an `unknown` family on either side with different model strings → `:same_family` (conservative).
- `pick_reviewer/2`: candidates = `[settings models.astra.model | settings models.astra.alternatives]`; return the first with `:other_family` (or `:no_writer`), else the first `:same_family`, else the first candidate with `:same_model_fresh`. Add `models.astra.alternatives: []` to the settings schema and defaults.

### Tests
Family matching and precedence of your file; each diversity level; `pick_reviewer` ordering, including the flagged last resort.

**Expected result.**
- `Si.Models` maps `provider/model` strings to families, with `$SI_HOME/models.yml` taking precedence over `priv/models.yml`.
- It computes diversity levels.
- It picks a reviewer from `models.astra.model` and its alternatives, in the specified order.
