### Goal
Run one review round end to end: prepare Astra's checkout, start (or reuse) her session on the right model, send the context, receive the verdict through `si_verdict`, and persist it.

### Context
`01-architecture.md` §5.1; `04-protocols.md` §2.4 (tools; `si_verdict` terminates the turn).

### Deliverables
- `lib/si/review/runner.ex` (`Si.Review.Runner`), the `si_verdict` tool handler `lib/si/review/verdict_handler.ex` registered with `Si.Bridge.Tools` at application start.
- Tests `test/si/review/runner_test.exs` (`@tag :pi`, si-faux scripts).

### Specification
```elixir
@spec run_round(Si.Review.Thread.t(), Si.Evidence.Snapshot.t(), Si.Checks.Summary.t() | nil, keyword()) ::
        {:ok, Si.Review.Review.t()} | {:error, :no_verdict | :timeout | term()}
#   opts: task_file, model (override), progress (fun receiving status strings), faux (test session opts)
```
Steps:
1. **Model**: `Si.Models.pick_reviewer(thread.writer_model, candidates)` unless `opts[:model]`; record `diversity_level` (`:no_writer` is stored as `other_family` for reporting and flagged in the review row's details as `writer_unknown`).
2. **Checkout**: if `thread.astra_worktree_id` exists and is `ready`, `Si.Worktrees.reset(wt, snapshot.commit_sha)`; else create a worktree `purpose: :astra` at `snapshot.commit_sha` and store its id on the thread.
3. **Session**: if the thread's Astra session is alive and idle, reuse it; else `Si.Sessions.start(role: "astra", profile: "reviewer", cwd: checkout path, model: model, thinking: settings models.astra.thinking, review_thread_id: thread.id, extra args: ["--append-system-prompt", <path of priv/prompts/astra/review.md>])` and store `astra_session_id`.
4. `Si.Review.start_review/3` (status `running`, `prompt_version` = hash of the review prompt). Progress: `Astra (<model>, <diversity>) is reviewing round <n>…`.
5. Subscribe to `"review:<thread_id>"`; `Si.Sessions.prompt(session, Context.build(...))`.
6. The `si_verdict` handler: finds `running_review_for_session(session_id)`; parses with `Verdict.from_args(args, open_findings)`; on `{:error, msg}` returns the error to the tool (Astra can correct and call again in the same turn); on success `record_verdict/2` and returns `%{recorded: true, review_id: id}`.
7. Wait for `{:review_recorded, review}`. If the session becomes idle without a verdict: send one follow-up `You have not called si_verdict yet. Finish the review now and call si_verdict once.`; if idle again without a verdict → review `status: error`, `{:error, :no_verdict}`. Overall timeout `review.verdict_timeout_s` → `status: timeout`, abort the session's turn, `{:error, :timeout}`.
8. Cost cap (until M08's budgets take over): after each `agent_settled` of Astra's session, call `get_session_stats`; when the `cost` spent since this review started exceeds `review.max_cost_usd` (default 2.0), abort the turn, set the review to `error` with reason `over_budget`, and create an inbox item with options `raise` / `stop` (Pair F-17: no default budget).
9. Leave the Astra session running (idle) for later rounds; T05.07 parks or stops it.

### Tests
(`@tag :pi`; fixture repo with a small change; si-faux scripts for Astra)
- Approve: script calls `si_verdict` with approve → review recorded, approval row for the snapshot.
- Revise: two blocking findings with evidence → findings stored open; round 1.
- Invalid then valid: first call approve-with-blocking (tool error), second call revise → one recorded review.
- No verdict: script replies with text only, then (after the reminder) text again → `{:error, :no_verdict}`, status error.
- No verdict then verdict after the reminder → recorded.
- Timeout: a script that never finishes (slow faux streaming) with a 2 s timeout → `{:error, :timeout}`.
- Diversity: writer `openai/gpt-5`, candidates `[openai/gpt-5, openrouter/kimi-k2]` → picks kimi with `other_family`.

**Expected result.**
- `Si.Review.Runner.run_round/4` runs one review round from start to finish:
  - it picks a model with diversity, prepares Astra's checkout, and starts or reuses her read-only session with the review prompt;
  - it sends the context and records the verdict that arrives through `si_verdict`.
- It handles a missing verdict, a timeout and the interim cost cap.
- It leaves Astra's session idle for the next round.
