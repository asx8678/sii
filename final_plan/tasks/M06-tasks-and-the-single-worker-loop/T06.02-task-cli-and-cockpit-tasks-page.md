### Goal
Add, inspect and cancel tasks from the CLI and see them live in the cockpit.

### Deliverables
- `lib/si/cli/commands/task.ex`; `SiWeb.TasksLive`, `SiWeb.TaskLive` (`/tasks/:id`); tests.

### Specification
```
si task add "<title>" [--repo PATH] [--description TEXT | --description-file FILE]
            [--scope GLOB]... [--test-path GLOB]... [--acceptance TEXT]... [--depends-on ID]...
            [--tier quick|standard|full] [--priority N]
si task list [--status S] [--repo PATH]
si task show <id> [--ledger]
si task cancel <id>
si fix "<text>" [--repo PATH]
```
- `add`: registers the repo if needed; prints `Created tsk_… (ready)`.
- `list`: table `ID · STATUS · ROUND · TITLE · REPO · AGE`.
- `show`: all fields, attempts, the review thread id, the last 20 events (`--ledger` output comes in T06.08).
- `cancel`: transition to `cancelled` (stops the worker session if one is assigned, via the loop in T06.05; in this task just the transition).
- `si fix "<text>"`: the quick path for a small fix from the terminal. Creates a `quick`-tier task in the current repository (title = the first line, description = the text), then streams its status changes until it lands, escalates or fails, and prints the delivery branch.
- Cockpit: list with status badges and filters (Active, Waiting on you, Landed, Cancelled); detail page with fields, attempts, links to the review thread and sessions; live updates from `"tasks"`.
