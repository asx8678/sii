### Goal
One summary per task: attempts, rounds, models, costs, check results, verdicts, decisions and durations. It feeds the CLI, the cockpit and later the Lead.

### Deliverables
- `lib/si/ledger.ex` (`Si.Ledger`), CLI `si task show <id> --ledger`, a ledger panel on the task page; tests `test/si/ledger_test.exs`.

### Specification
```elixir
@spec task(String.t()) :: map()
```
Returns:
```elixir
%{task: %{id, title, status, tier},
  rounds: [%{n, snapshot_id, checks: [%{check, status, duration_ms}], review: %{verdict, reviewer_model, blocking, notes} | nil, fixed_by: "writer" | "astra" | nil}],
  attempts: [%{n, session_id, model, started_at, ended_at, status}],
  models: %{builder: [...], reviewer: [...]},
  cost: %{usd: float, by_role: %{builder: float, astra: float, other: float}, tokens: %{input, output, cached}},
  durations_ms: %{total, working, checking, reviewing, queued},
  decisions: [%{at, type, summary}]}
```
- Costs sum `model_calls.cost_usd` of all sessions with this `task_id` or the task's review thread.
- Durations come from `task.transitioned` events (time spent in each status group).
- Decisions: task transitions, review verdicts, policy decisions, merge events, inbox items for the task.

### Tests
Build a task history with fixtures (events + rows) and assert the ledger values, including cost aggregation by role.

### Acceptance criteria
Tests pass; `bin/ci` passes.

### Verify
```bash
mix test test/si/ledger_test.exs
```

### After implementing

Do this after the Verify commands pass. Run `bin/task-check` first, then these checks. Each check states the result you must see. Any other result means the task is not done: fix the cause in the code (never by changing what a test expects), or rewrite the part named under **Redo if**, then run `bin/task-check` and every check below again from the top. The limits on fix attempts, how to redo a task, and the evidence the completion note needs are in [10-after-each-task](../../10-after-each-task.md).

**Expected result.** `Si.Ledger.task/1` returns one map per task: rounds, attempts, models, costs by role, time spent in each status group, and decisions. The CLI and the task page show it.

**Checks**

   Expected: rounds, cost and durations printed.

**Redo if**
