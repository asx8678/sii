### Goal
Landed work gets an informative commit message with trailers and a delivery branch, and every temporary session and worktree of the task is cleaned up.

### Context
`03-data-model.md` (`deliveries`); delivery targets in the blueprint (branch needs no approval).

### Deliverables
- Migration `create_deliveries`; `lib/si/delivery.ex` (`Si.Delivery`); cleanup in `Si.Tasks.Loop`; tests `test/si/delivery_test.exs`.

### Specification
- `Si.Delivery.commit_message(task, item) :: String.t()`:
  ```
  <task title>

  <si_report summary of the approved round, wrapped at 72 columns>

  Si-Task: <task_id>
  Si-Run: <run_id or "none">
  Si-Snapshot: <snapshot_id>
  Si-Writer-Model: <provider/model>
  Si-Reviewer-Model: <provider/model>
  Si-Approval: <approval id>
  ```
- `Si.Delivery.deliver(task, landed_sha) :: {:ok, Delivery.t()}` for target `branch` (the default and the only target in M06): create `refs/heads/si/task/<task_id>` at `landed_sha` (old = nil; if it exists, update with CAS); insert `deliveries` (`status: "done"`, `ref`); event `delivery.created`.
- Cleanup after landing or cancellation: stop the builder session, remove the builder worktree, stop and remove the review thread's Astra sessions and worktrees. Snapshot refs are kept (pruned later by a reconciler).

### Tests
Message format (golden); branch created at the landed commit; re-delivery updates the branch; cleanup removes the worktrees (`git worktree list`) and stops sessions.

### Acceptance criteria
Tests pass; `bin/ci` passes.

### Verify
```bash
mix test test/si/delivery_test.exs
```

**Expected result.**
- Landed commits carry the trailer message.
- Delivery creates `si/task/<id>` at the landed commit, updating an existing branch with compare-and-swap.
- Cleanup stops the task's sessions and removes its worktrees; snapshot refs are kept.

**Checks**
1. `git log -1 --format=%B si/task/<id>` in the test repo.
   Expected: the golden message, with all six trailers.
2. `git worktree list` and `Si.Sessions.list(task_id: id)` after landing.
   Expected: no worktree of the task, and every session of the task `stopped`.
3. `git for-each-ref refs/si/snapshots` after cleanup.
   Expected: the task's snapshot refs still exist.

**Redo if**
- Cleanup removes snapshot refs or approvals. Only T11.03's reconciler prunes those.
