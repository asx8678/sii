### Goal
Land approved snapshots onto `si/integration` one at a time: replay the change on the current head, run the build and the full test suite, and move the branch only if they pass. Conflicts and failures go back to the writer.

### Context
`01-architecture.md` §5.4; `03-data-model.md` (`merge_items`, §3.4).

### Deliverables
- Migration `create_merge_items`; `lib/si/merge_queue.ex` (`Si.MergeQueue`), `lib/si/merge_queue/queue.ex` (GenServer per repo, registered `{:merge_queue, repo_id}`, under `Si.MergeQueue.Supervisor`), `lib/si/merge_queue/item.ex`.
- Tests `test/si/merge_queue_test.exs`.

### Specification
```elixir
@spec enqueue(Si.Tasks.Task.t(), Si.Evidence.Snapshot.t()) :: {:ok, Item.t()}
@spec status(Si.Repos.Repo.t()) :: [Item.t()]
```
Processing (one item at a time, FIFO by `position`):
1. Queue worktree: `purpose: :queue` at `Si.Paths.queue_dir(repo_id)` (created once); reset to the integration head `H`.
2. `git cherry-pick --no-commit <snapshot.commit_sha>`; conflict → `git cherry-pick --abort`, eject with `%{reason: "conflict", files: [...]}` (from `git diff --name-only --diff-filter=U` before aborting).
   Empty result (change already present) → mark landed with `landed_sha = H` (no-op).
3. `git commit -m <message>` with Si's identity, message from `Si.Delivery.commit_message(task, item)` (T06.07; until then `"<task title>\n\nSi-Task: <task_id>"`). New commit `C`.
4. `Si.Evidence.freeze_ref(repo, C, H)` → landing snapshot; `Si.Checks.run_all(landing_snapshot, checks: [:build, :tests], tests_mode: :all)` (add a `tests_mode: :all` option to the tests check that forces `test_all`).
5. Pass → `Si.Git.update_ref(repo, "refs/heads/si/integration", C, H)`:
   - `:ok` → item `landed` (`landed_sha: C`), event `merge.landed`, task `queued → landed`, `Si.Tasks.promote_dependents/1`, notify the task loop and delivery (T06.07).
   - `{:error, :stale}` (integration moved) → retry from step 1, at most 3 times, then eject with `reason: "integration kept moving"`.
6. Fail → eject with the failed check and log path.
Ejection: item `ejected` with `error`, event `merge.ejected`, and the task loop receives `{:ejected, reason, feedback}`. For conflicts, Si rebases the worker's worktree before handing it back: in the worker worktree, `git checkout --detach --force <new H>` after saving the snapshot, then `git cherry-pick --no-commit <snapshot.commit_sha>`, leaving conflict markers in the listed files; update the worktree's base to the new `H`; the feedback says which files have conflicts and that the base moved.

### Tests
- Two approved tasks touching different files land in order; the integration branch has two new commits; each landing ran checks.
- Conflict: both tasks change the same line → the second is ejected; its worker worktree contains conflict markers and the new base; after resolving and re-reporting, it lands.
- `test_all` fails on the combined result → ejected with the log path.
- Stale head (a test hook moves `si/integration` between steps 4 and 5) → retried and landed.

### Acceptance criteria
Tests pass; `bin/ci` passes; the integration branch never points to a commit whose checks failed (assert in tests).

**Expected result.**
- The merge queue lands approved snapshots on `si/integration` one at a time:
  1. cherry-pick onto the current head;
  2. run build and the full tests;
  3. move the branch with compare-and-swap.
- On a conflict it ejects the item, puts conflict markers in the worker's worktree and updates its base.
- The integration branch never points to a commit whose checks failed.

**Checks**
1. After the conflict test, the worker's worktree.
   Expected: conflict markers in the listed files, and the worktree's base updated to the new head.
2. The stale-head test.
   Expected: a retry that lands, with at most 3 attempts.
3. The assertion that `si/integration` never points to a failing commit.
   Expected: it runs after every landing in the tests.
4. The queue worktree.
   Expected: created once at `Si.Paths.queue_dir(repo_id)` and reused.

**Redo if**
- The integration ref is moved with `git branch -f`, `git push` or anything without compare-and-swap. Rewrite it with `update_ref/4`.
