### Goal
Active worker and warm worktrees keep a seeded Fovea cache even after Fovea evicted it.

### Deliverables
Op `fovea.cache_exists {root}` in the adapter; `lib/si/reconcilers/fovea_cache.ex`; tests with a stubbed adapter.

### Specification
Every 5 minutes: for active `:worker`/`:warm` worktrees of repos whose base checkout has a cache, if the worktree's cache is missing → `Si.Fovea.seed/2`.

### Tests
Missing cache → seed called; existing → nothing.

### Acceptance criteria
Tests pass; `bin/ci` passes.

### Verify
```bash
mix test test/si/reconcilers/fovea_cache_test.exs
```

### After implementing

Do this after the Verify commands pass. Run `bin/task-check` first, then these checks. Each check states the result you must see. Any other result means the task is not done: fix the cause in the code (never by changing what a test expects), or rewrite the part named under **Redo if**, then run `bin/task-check` and every check below again from the top. The limits on fix attempts, how to redo a task, and the evidence the completion note needs are in [10-after-each-task](../../10-after-each-task.md).

**Expected result.** Active worker and warm worktrees get their Fovea cache seeded again after Fovea evicted it.

**Checks**
1. A missing cache (stubbed adapter).
   Expected: `Si.Fovea.seed/2` is called once.
2. An existing cache.
   Expected: nothing happens.

**Redo if**
- It seeds worktrees that are not active. Limit it to `:worker` and `:warm` worktrees.
