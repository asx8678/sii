### Goal
Si's disk and database use stays bounded over months of use (Pair F-30: unbounded growth, no cleanup).

### Deliverables
- Settings `retention.*`; migration `create_analytics_daily`; `lib/si/reconcilers/retention.ex`; CLI `si gc [--dry-run] [--only KIND]`; tests.

### Specification
Defaults (all configurable):

| Kind | Rule |
|---|---|
| `logs` | check logs and session stderr logs older than 30 days; `node.log` is rotated by the logger (T11.12) |
| `sessions` | Pi session files of sessions `stopped`/`lost` for more than 30 days, unless an open task, review thread or run references the session |
| `analytics` | `model_calls`, `turns`, `tool_calls`, `fabric_execs` older than 90 days are first aggregated into `analytics_daily` (day, model, role, provider: calls, tokens by kind, cost, errors), then deleted |
| `evals` | eval work directories 7 days after their report is written |
| `patches` | patch files older than 30 days |
| `branches` | `si/task/*` and `si/astra-fix/*` branches whose commit is contained in the default branch, or older than 30 days, and not referenced by an open delivery or pull request |

- `events` are never deleted (they are the audit trail and stay small); snapshots and worktrees are handled by T11.03.
- Nothing referenced by an open task, thread, run or inbox item is removed.
- `si gc --dry-run` lists what would be removed with sizes; `si gc` does it; the reconciler runs daily.

### Tests
Each kind with fixtures (old and new items, referenced and unreferenced); analytics aggregation totals equal the deleted rows' totals; dry run removes nothing.

### Acceptance criteria
Tests pass; `bin/ci` passes.

**Expected result.**
- Retention rules keep disk and database use bounded.
- Analytics rows are rolled up into `analytics_daily` before they are deleted.
- Events and referenced items are never deleted.
- `si gc --dry-run` changes nothing.

**Checks**
1. `bin/si gc --dry-run`, before and after.
   Expected: a list with sizes; file counts and row counts are identical before and after.
2. Aggregation totals.
   Expected: equal to the deleted rows' totals, per day, model, role and provider.
3. The `events` row count after `si gc`.
   Expected: unchanged.

**Redo if**
- Anything referenced by an open task, thread, run or inbox item is removed. Add the reference checks before deleting.
