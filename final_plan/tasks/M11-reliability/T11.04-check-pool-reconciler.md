### Goal
Keep each repository's check pool at its target size with working slots, and release slots whose holder died.

### Deliverables
`lib/si/reconcilers/check_pool.ex`; tests.

### Specification
Ops: create missing slots; recreate `broken` slots; release `leased` slots whose `lease_owner` process is dead (owner pid stored alongside the owner string) or whose lease is older than 2 hours.

### Tests
Missing, broken and stale-lease cases.

### Acceptance criteria
Tests pass; `bin/ci` passes.

### Verify
```bash
mix test test/si/reconcilers/check_pool_test.exs
```

### After implementing

Do this after the Verify commands pass. Run `bin/task-check` first, then these checks. Each check states the result you must see. Any other result means the task is not done: fix the cause in the code (never by changing what a test expects), or rewrite the part named under **Redo if**, then run `bin/task-check` and every check below again from the top. The limits on fix attempts, how to redo a task, and the evidence the completion note needs are in [10-after-each-task](../../10-after-each-task.md).

**Expected result.** Each check pool stays at its target size with working slots. Broken slots are recreated. Leases whose holder died, or that are older than 2 hours, are released.

**Checks**
1. A pool with one missing, one broken and one stale-leased slot.
   Expected: all three are back to `idle` and working after one run.
2. A live holder with a young lease.
   Expected: untouched.

**Redo if**
- A live lease is released. Check that the owner process is actually dead before releasing.
