### Goal
Detect when the integration branch no longer contains what Si landed, or was moved by someone else, and requeue interrupted items.

### Deliverables
`lib/si/reconcilers/merge_queue.ex`; event `merge.external_change`; tests.

### Specification
- For each `landed` item from the last 7 days: `Si.Git.ancestor?(repo, landed_sha, integration head)`; if not → inbox item `kind: "external_push"` (`Changes on si/integration were rewritten`), options `["reland", "accept"]`; `reland` enqueues the task's approved snapshot again.
- Items in `testing` with no queue process → back to `queued`.
- Integration head commits without an `Si-Task:` trailer since the last check → informational inbox item (auto-resolved) and event.

### Tests
Force-moving the integration branch backwards triggers the inbox item; `reland` requeues; an interrupted `testing` item is requeued.

### Acceptance criteria
Tests pass; `bin/ci` passes.

### Verify
```bash
mix test test/si/reconcilers/merge_queue_test.exs
```

### After implementing

Do this after the Verify commands pass. Run `bin/task-check` first, then these checks. Each check states the result you must see. Any other result means the task is not done: fix the cause in the code (never by changing what a test expects), or rewrite the part named under **Redo if**, then run `bin/task-check` and every check below again from the top. The limits on fix attempts, how to redo a task, and the evidence the completion note needs are in [10-after-each-task](../../10-after-each-task.md).

**Expected result.**
- If `si/integration` was rewritten, the owner is asked whether to re-land the lost items.
- Interrupted `testing` items are queued again.
- Commits on the integration head without a `Si-Task:` trailer are reported.

**Checks**
1. Move the integration branch backwards.
   Expected: an `external_push` inbox item; `reland` queues the approved snapshot again.
2. An item in `testing` with no queue process.
   Expected: back to `queued`.

**Redo if**
- The reconciler force-moves `si/integration` itself. It only reports and requeues.
