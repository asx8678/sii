### Goal
Keep worktrees, directories and snapshot refs consistent with the database, and clean up what nothing uses any more.

### Deliverables
`lib/si/reconcilers/worktrees.ex`; tests.

### Specification
- Observed per repo: `git worktree list --porcelain` and the directories under `$SI_HOME/worktrees/<repo>`, `checks/<repo>`, `queue/<repo>`.
- Ops: remove directories that have no row and are older than 1 hour; `git worktree prune`; mark rows `broken` whose directory is missing (check slots are handled by T11.04); remove worktrees of tasks that are `landed` or `cancelled` for more than 1 hour; delete `refs/si/snapshots/<id>` for snapshots older than 30 days whose task is landed or cancelled and that no delivery or approval of an open item references.

### Tests
Each op with fixtures; nothing referenced is ever removed.

### Acceptance criteria
Tests pass; `bin/ci` passes.

### Verify
```bash
mix test test/si/reconcilers/worktrees_test.exs
```

### After implementing

Do this after the Verify commands pass. Run `bin/task-check` first, then these checks. Each check states the result you must see. Any other result means the task is not done: fix the cause in the code (never by changing what a test expects), or rewrite the part named under **Redo if**, then run `bin/task-check` and every check below again from the top. The limits on fix attempts, how to redo a task, and the evidence the completion note needs are in [10-after-each-task](../../10-after-each-task.md).

**Expected result.**
- Worktree rows, directories and snapshot refs stay consistent.
- Unused ones are cleaned up by the rules.
- Nothing that is referenced is ever removed.

**Checks**
1. A fixture with referenced and unreferenced worktrees and snapshots.
   Expected: only the unreferenced items older than their limits are removed.
2. `git worktree list` after the reconciler runs.
   Expected: no entries point to missing directories (it pruned them).

**Redo if**
- The reconciler deletes anything without first checking tasks, deliveries and approvals. Add the reference checks before any deletion.
