### Goal
Every model call gets a cost in one unit: API dollars, or GPU time at a rate you set for your own servers.

### Deliverables
- Prices in `priv/models.yml` (per catalog entry: `price: {input_per_mtok, output_per_mtok, cached_input_per_mtok}`; placeholders the owner must verify, marked `verified: false`), GPU rates in `scheduler.pools[].gpu_rate_usd_per_s`.
- `lib/si/cost.ex` (`Si.Cost`); cost filled during ingestion; tests `test/si/cost_test.exs`.

### Specification
```elixir
@spec for_call(map()) :: %{cost_usd: float() | nil, gpu_seconds: float() | nil}   # a model_calls row with tokens
@spec sum(keyword()) :: float()                                                     # filters: session_id, task_id, run_id, role, since
```
- Priority of sources: (1) `usage.cost` reported by Pi (provider-reported), (2) catalog price × tokens (`cached_input` for cache reads), (3) GPU pools: `gpu_seconds = latency_ms / 1000` and `cost = gpu_seconds × gpu_rate_usd_per_s`, (4) otherwise nil (unknown, counted as 0 in sums and flagged).
- `Si.Bridge.Ingest` calls `for_call/1` when the usage arrives and stores both fields.

### Tests
Each source; cached tokens priced at the cached rate; GPU pool match; sums by role (join sessions).

### Acceptance criteria
Tests pass; `bin/ci` passes.

**Expected result.**
- Every model call gets `cost_usd` and/or `gpu_seconds` from the first source that applies:
  1. the provider-reported cost;
  2. the catalog price;
  3. the GPU rate.
- An unknown cost is stored as `nil` and flagged.
- Catalog prices are placeholders marked `verified: false`.

**Checks**
1. One call per source, in the tests.
   Expected: the right source wins in each case, and cached tokens are priced at the cached rate.
2. `grep -c 'verified: false' priv/models.yml`.
   Expected: every price entry is marked, because the owner verifies the prices.
3. A call with no cost source.
   Expected: `cost_usd: nil`, counted as 0 in sums and flagged.

**Redo if**
- The catalog price overrides a provider-reported cost. Rewrite the order of sources.
