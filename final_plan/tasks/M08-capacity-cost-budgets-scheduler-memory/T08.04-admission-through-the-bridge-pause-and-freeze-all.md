### Goal
Connect the bridge's slot gate to the scheduler, and give you pause/resume per session and a kill switch that freezes all Si work.

### Deliverables
- `Si.Bridge.Slots` uses `Si.Scheduler`; `lib/si/freeze.ex` (`Si.Freeze`); CLI `si session pause|resume <id>`, `si freeze`, `si resume`; cockpit Freeze-all button; tests.

### Specification
- `slot_request` → `Si.Scheduler.request/2` with a reply fun that calls `Phoenix.Channel.reply(ref, {:ok, reply})`; `slot_release` → `Si.Scheduler.release/2`.
- Pause/resume: `Si.Scheduler.hold({:session, id}, :paused)` / `unhold`; the session's next model call waits. Shown in the cockpit.
- `si freeze` (`Si.Freeze.freeze/0`): set a global flag checked by the dispatcher, the task loops and (later) the Lead; hold `{:all, :all}` for Si sessions only (user sessions are never held); abort running turns of Si sessions (RPC `abort`); event `system.frozen`. `si resume` clears it.
- Your own sessions keep running untouched.
- Cockpit: Pause/Resume buttons on the session page and a Freeze all / Resume all button in the top bar, with the current state visible.

### Tests
Channel test: requests beyond a pool's concurrency wait until a release; pause holds a session's calls; freeze stops the dispatcher from starting new tasks and holds calls; resume releases them.

### Acceptance criteria

**Expected result.**
- The bridge's slot gate asks the scheduler.
- Sessions can be paused and resumed.
- `si freeze` stops new work and holds and aborts Si's sessions, while the owner's own sessions keep running.
- The cockpit shows the state and the controls.

**Checks**
1. `si freeze` with a user session and a Si session active.
   Expected: the Si session's next call waits and its running turn is aborted; the user session's calls are granted.
2. `si resume`.
   Expected: the held calls are granted, and the dispatcher starts tasks again.
3. Requests beyond a pool's concurrency.
   Expected: they wait until a release.

**Redo if**
- Freeze holds user sessions. Rewrite it: the owner's own sessions are never held.
