### Goal
Caps per task, run and supervision share; a warning at 80% and a stop at 100% that holds further model calls until you decide.

### Deliverables
- Settings `budgets.task_default_usd` (default 2.0) added; `lib/si/budgets.ex` (`Si.Budgets`); tests `test/si/budgets_test.exs`.

### Specification
```elixir
@spec status({:task | :run | :supervision, String.t()}) :: %{spent: float(), cap: float(), pct: float(), state: :ok | :warn | :stop}
@spec raise_cap({atom(), String.t()}, float()) :: :ok
```
- Caps: task → `task.delivery["budget_usd"]` or the default; run → workflow budget (M09) or `run_default_usd`; supervision → `supervision_share × run cap`, counting sessions with roles `lead`, `critic`, `arbiter`, `judge`.
- Re-evaluated whenever a model call gets its cost (subscribe to a `{:model_call_costed, row}` broadcast added in T08.01).
- Crossing `warn_at` → event `budget.warned` + an informational inbox item (`wait_policy: "default_after"`, 0 s, auto-resolved; it notifies).
- Reaching the cap → event `budget.stopped`; the scheduler (T08.03) holds all sessions of that scope; inbox item `kind: "budget"` with options `["raise", "stop"]` (recommended `raise` by 50%). `raise` → `raise_cap/2` + release holds; `stop` → cancel the task (or run).
- Budgets replace the interim caps from T05.04 (`review.max_cost_usd`) and T06.05 (`tasks.max_cost_usd`): those settings become the default caps for review rounds and tasks, and the interim `get_session_stats` checks are removed.

### Tests
Warn and stop thresholds; supervision share counted only for supervision roles; raise releases (assert through the scheduler's hold API using a stub).

### Acceptance criteria
Tests pass; `bin/ci` passes.

**Expected result.**
- Caps apply per task, per run and for the supervision share.
- A warning at `warn_at`, and a stop at 100% that holds further calls through the scheduler until the owner raises the cap or stops the work.
- The interim caps from T05.04 and T06.05 are replaced.

**Checks**
1. `grep -rn 'get_session_stats' lib`.
   Expected: no cost-cap checks remain; budgets use costed model calls.
2. Spending that crosses 80%, then 100%.
   Expected: one `budget.warned`, then `budget.stopped` and an inbox item offering `raise` (with a 50% raise recommended) and `stop`.
3. The supervision share.
   Expected: only sessions with the roles lead, critic, arbiter and judge count.

**Redo if**
- The stop aborts sessions instead of holding their calls. Rewrite it to hold through the scheduler.
