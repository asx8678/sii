### Goal
Cut task start time by keeping a few builder sessions already started in worktrees at the integration head.

### Deliverables
- `lib/si/warm_slots.ex` (`Si.WarmSlots`); settings `workers.warm_slots` (map role → count, default `{builder: 1}`); dispatcher uses it; tests.

### Specification
```elixir
@spec take(Si.Repos.Repo.t(), String.t(), String.t()) :: {:ok, %{worktree: Worktree.t(), session_id: String.t()}} | :none   # repo, role, model
```
- Per repository with recent activity (a task in the last 24 h), maintain the configured count of warm slots: a worktree (`purpose: :warm`) at the integration head and an idle session (role, profile, model from settings) in it. Respect `Si.Memory.can_start?/1`.
- `take/3`: returns a slot with the same model or `:none`; resets the worktree to the latest integration head before returning; converts the worktree to `purpose: :worker` and sets the session's `task_id` column (the `si_task` handler reads the task from the session row); refills asynchronously.
- Warm sessions are stopped after 30 minutes without a take, and when the repo has no activity.

### Tests
Take returns a ready slot and triggers a refill; model mismatch → `:none`; the worktree is at the latest head after a take (move the integration branch between refill and take); idle expiry.

### Acceptance criteria
Tests pass; `bin/ci` passes; with a warm slot, the time from `ready` to the first `si_task` call drops (log it in the test with fake Pi; no hard threshold).

**Expected result.**
- Warm builder sessions wait in worktrees at the integration head.
- `take/3` returns one with the same model, resets it to the latest head, turns it into a worker and refills asynchronously.
- Idle warm sessions stop after 30 minutes.

**Checks**
1. Move the integration branch between the refill and `take/3`.
   Expected: the taken worktree is at the new head.
2. A different model.
   Expected: `:none`.
3. The time from `ready` to the first `si_task` call, with and without a warm slot (fake Pi).
   Expected: shorter with the slot. Record both numbers.

**Redo if**
- `take/3` returns a slot without resetting it to the latest head. Rewrite it: stale bases cause conflicts later.
