### Goal
Two ready-made workflows: Astra reviewing an existing branch or pull request as a run, and fixing a failing test suite without weakening tests.

### Deliverables
- The `review` step executor; completed `review-only.yml` and `fix-tests.yml` templates; tests (`@tag :pi`).

### Specification
- `review-only` (inputs `head`, `base`): a `review` step that freezes `head` against `base` and runs review rounds like `si review` (writer unknown; fix policy from the workflow, default `writer`, which means findings are reported to you); the run summary contains the verdict and findings; delivery `none`, or the Astra fix branch when `fix: astra|auto` produced one.
- `fix-tests` (input `command`, default the profile's `test_all`): intake runs the command in a check slot and requires it to fail (else the run ends with `nothing to fix`); a build step with the task text `Make these failing tests pass without changing what they check: <failure summary>`; checks include `test_integrity` with no override allowed and `tests` with `tests_mode: :all`; Astra review; deliver to a branch.

### Tests
review-only on a fixture branch: approve and revise paths; fix-tests: a fixture where a function is broken → the faux builder fixes it → lands; a faux builder that deletes the failing test is blocked by test integrity.

### Acceptance criteria
Tests pass; `bin/ci` passes.

The limits on fix attempts, how to redo a task, and the evidence the completion note needs are in [10-after-each-task](../../10-after-each-task.md).

**Expected result.**
- `review-only` reviews an existing branch as a run.
- `fix-tests` fixes a failing suite without weakening it:
  - it is refused when nothing fails;
  - `test_integrity` runs with no override allowed;
  - `tests` runs with `tests_mode: :all`.

**Checks**
1. `fix-tests` on a suite that passes.
   Expected: the run ends with `nothing to fix`.
2. A faux builder that deletes the failing test.
   Expected: blocked by `test_integrity`, and no override is possible.
3. `review-only`, with both an approve and a revise script.
   Expected: the run summary holds the verdict and the findings.

**Redo if**
- `fix-tests` allows an override of `test_integrity`. Remove it.
