### Goal
Deliver finished work as a pull request or a local merge (both after your approval), or as a patch file.

### Deliverables
- `Si.Delivery` targets `pr`, `patch`, `merge_local`; the deliver step executor; tests with a fake `gh` and a bare remote.

### Specification
- `pr`: inbox approval (`kind: "approval"`, `Open a pull request for <title>?`, options `approve`/`skip`); on approve: `git push origin refs/heads/si/run/<run_id>:refs/heads/si/run/<run_id>` (or the task branch for single tasks), then `gh pr create --base <default_branch> --head si/run/<run_id> --title <title> --body <ledger summary with trailers>`; store the URL. `gh` missing or unauthenticated → delivery `failed` with the message and an inbox note.
- `patch`: `git format-patch <run base>..<integration head> -o $SI_HOME/patches/<run_id>/`; store the directory path.
- `merge_local`: inbox approval; preconditions checked at execution time: the repo's main working tree is clean (`Si.Git.clean?/1`), on the default branch, and no session (Si or yours) with that `cwd` is `running` or `settling`; then `git merge --ff-only si/integration` in the main working tree; a non-fast-forward situation → `failed` with guidance (no automatic merge commits).
- Wait policy `wait` for both approvals.

### Tests
Fake `gh` script records its arguments; a bare repo as `origin` receives the pushed branch; patch files are created; `merge_local` refuses a dirty tree and a running session, and fast-forwards a clean one.

### Acceptance criteria
Tests pass; `bin/ci` passes.

**Expected result.**
- Delivery works to a pull request (after the owner approves, through `gh`), to patch files, and as a local fast-forward merge (after approval and precondition checks).
- A delivery failure leaves clear messages.

**Checks**
1. The tests.
   Expected: they use a fake `gh` script and a bare repository as `origin`. Never push to a real remote or run the real `gh pr create` during this task.
2. `merge_local` with a dirty tree, and with a running session in that repository.
   Expected: refused both times, with the reason.
3. `patch`.
   Expected: `git format-patch` files under `$SI_HOME/patches/<run_id>/`.

**Redo if**
- `merge_local` makes a merge commit or merges without fast-forward. Rewrite it with `--ff-only` and guidance on failure.
