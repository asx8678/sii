### Goal
Register repositories with Si, detect their default branch, and create the integration branch `si/integration`.

### Context
`03-data-model.md` §2 (`repos`), `02-repo-layout.md` §7 (refs).

### Deliverables
- Migration `create_repos`; `lib/si/repos.ex` (`Si.Repos`), `lib/si/repos/repo.ex` (schema).
- CLI commands `lib/si/cli/commands/repo.ex` (`si repo add|list|show`), registered in `Si.CLI.Server`.
- Tests: `test/si/repos_test.exs`, `test/si/cli/repo_command_test.exs`.

### Specification
```elixir
@spec add(Path.t()) :: {:ok, Repo.t()} | {:error, :not_a_git_repository | :bare_repository | Si.Git.Error.t()}
@spec get(String.t()) :: Repo.t() | nil
@spec get!(String.t()) :: Repo.t()
@spec get_by_path(Path.t()) :: Repo.t() | nil        # accepts any path inside the work tree
@spec resolve(String.t()) :: {:ok, Repo.t()} | {:error, :not_found}   # repo id or a path inside a registered repo
@spec list() :: [Repo.t()]
@spec integration_head(Repo.t()) :: {:ok, String.t()} | {:error, term()}
```
`add/1`:
1. `Si.Git.toplevel(path)` → canonical toplevel (this also resolves symlinks). Not a work tree → `{:error, :not_a_git_repository}`; `git rev-parse --is-bare-repository` true → `{:error, :bare_repository}`.
2. If a repo with that path exists, return it unchanged (idempotent).
3. Default branch: `git symbolic-ref --short refs/remotes/origin/HEAD` minus the `origin/` prefix; else `main` if `refs/heads/main` exists; else `master`; else the current branch; else error `:no_branch`.
4. Integration branch: if `refs/heads/si/integration` does not exist, create it at the default branch head with `update_ref/4` (old = nil). Never move an existing one.
5. Insert the row with `name` = basename of the toplevel, and append event `repo.added` (stream `repo:<id>`) in the same transaction.

CLI:
- `si repo add [path]` (default: `ctx.cwd`) → prints `Added <name> (<id>) · default <branch> · integration si/integration at <short sha>`; exit 0. On error, a one-line message and exit 1.
- `si repo list` → table columns `ID`, `NAME`, `PATH`, `DEFAULT`, `INTEGRATION`.
- `si repo show [path|id]` → key/value lines including profile status (`missing`, `unconfirmed`, `confirmed`; the profile columns exist from T01.03, before that print `missing`).

### Tests
- `add/1` on a subdirectory path registers the toplevel.
- `add/1` twice returns the same id.
- Default branch detection: with `main`; with only `master`; with a fake `origin/HEAD` (create `refs/remotes/origin/main` and `git symbolic-ref refs/remotes/origin/HEAD refs/remotes/origin/main`).
- Integration branch created at the default head; an existing `si/integration` pointing elsewhere is left alone.
- Non-git directory → `{:error, :not_a_git_repository}`.
- CLI: `add`, `list`, `show` outputs and exit codes (through `Si.CLI.Server.run/2`).

### Acceptance criteria
Tests pass; `bin/ci` passes; `si repo add` on this repository works against a running node.

**Expected result.**
- `Si.Repos.add/1` registers the canonical top level of a repository, and adding it again returns the same row.
- It detects the default branch, creates `si/integration` at that branch once and never moves it, and records `repo.added`.
- `si repo add`, `si repo list` and `si repo show` work against the running node.

**Checks**
1. Make a temporary repo with one commit. Run `bin/si repo add <tmp>` twice, then `git -C <tmp> rev-parse si/integration main`.
   Expected: the same repo id both times, and two identical SHAs.
2. Commit once more on `main`, then run `bin/si repo add <tmp>` again.
   Expected: `si/integration` still points to the old SHA.
3. `bin/si repo add <tmp>/sub` (a subdirectory), and `bin/si repo add` with the same repo reached through `/tmp/…` and through `/private/tmp/…`.
   Expected: the same repo id each time.
4. `bin/si repo add "$(mktemp -d)"; echo "exit=$?"` (not a git repository).
   Expected: a one-line message and `exit=1`.
5. `bin/si repo add .` in this repository (Verify), then `git branch --list 'si/*'`.
   Expected: `si/integration` at `main`. This is expected and harmless. Leave it.

**Redo if**
- The integration branch is created with `git branch`, or updated without compare-and-swap. Rewrite it with `Si.Git.update_ref/4` and `old = nil`.
