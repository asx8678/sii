### Goal
A single, safe way to run git from Si: separate stdout and stderr, timeouts that kill hung commands, structured errors, parsers for the porcelain formats Si needs, and a per-repository lock for operations that must not overlap.

### Context
`02-repo-layout.md` §7 (refs owned by Si). Every later git operation goes through this module.

### Deliverables
- `lib/si/git.ex` (`Si.Git`), `lib/si/git/error.ex` (`Si.Git.Error` exception), `lib/si/git/porcelain.ex` (`Si.Git.Porcelain` parsers), `lib/si/git/locks.ex` (`Si.Git.Locks`, supervised).
- `test/si/git_test.exs`, `test/si/git/porcelain_test.exs`, `test/si/git/locks_test.exs`.

### Specification
**Running git**
```elixir
@spec cmd(Path.t(), [String.t()], keyword()) :: {:ok, String.t()} | {:error, Si.Git.Error.t()}
@spec cmd!(Path.t(), [String.t()], keyword()) :: String.t()
```
Options: `timeout` (ms, default 60_000), `env` (extra `[{k, v}]`), `input` (not supported; raise if given), `allow_exit` (list of non-zero exit codes treated as success, e.g. `[1]` for `merge-base --is-ancestor`).
- Execute through `MuonTrap.cmd("/bin/sh", ["-c", "exec git \"$@\" 2>\"$SI_GIT_ERR\"", "git", "-C", dir, "-c", "core.hooksPath=/dev/null" | args], env: env, timeout: timeout)`, where `SI_GIT_ERR` is a temp file path; read and delete the file afterwards. This keeps stdout clean for parsing and captures stderr for errors.
- Base env for every call: `GIT_TERMINAL_PROMPT=0`, `LC_ALL=C`, `GIT_OPTIONAL_LOCKS=0` (for read-only commands such as `status`; pass `optional_locks: true` to omit it).
- Si's internal git commands never run repository hooks (`core.hooksPath=/dev/null`), so hooks can't slow down or block background work.
- Commits Si creates use `GIT_AUTHOR_NAME=Si`, `GIT_AUTHOR_EMAIL=si@localhost`, and the same for committer (helper `Si.Git.si_identity_env/0`).
- Timeout: MuonTrap returns `:timeout`; map it to `%Si.Git.Error{reason: :timeout}`.

`%Si.Git.Error{dir, args, exit_status, stderr, reason}`: `reason` is `:exit_status | :timeout | :not_a_repository`; `message/1` produces `git <args> failed in <dir> (exit 128): <first stderr line>`.

**Helpers** (each a thin wrapper around `cmd/3` plus a parser):
```elixir
@spec toplevel(Path.t()) :: {:ok, Path.t()} | {:error, Si.Git.Error.t()}          # rev-parse --show-toplevel
@spec work_tree?(Path.t()) :: boolean()
@spec rev_parse(Path.t(), String.t()) :: {:ok, String.t()} | {:error, Si.Git.Error.t()}   # rev-parse --verify <rev>^{commit} for commits; tree_of/2 for trees
@spec tree_of(Path.t(), String.t()) :: {:ok, String.t()} | {:error, Si.Git.Error.t()}
@spec head(Path.t()) :: {:ok, String.t()} | {:error, Si.Git.Error.t()}
@spec current_branch(Path.t()) :: {:ok, String.t() | nil}                            # nil when detached
@spec status(Path.t()) :: {:ok, Si.Git.Porcelain.status()} | {:error, Si.Git.Error.t()}  # status --porcelain=v2 -z --branch --untracked-files=all
@spec clean?(Path.t()) :: boolean()                                                   # no tracked changes and no untracked files
@spec ref_exists?(Path.t(), String.t()) :: boolean()                                  # show-ref --verify --quiet
@spec update_ref(Path.t(), String.t(), String.t(), String.t() | nil) :: :ok | {:error, :stale | Si.Git.Error.t()}  # CAS: old nil means "must not exist" (use 40 zeros)
@spec delete_ref(Path.t(), String.t()) :: :ok | {:error, Si.Git.Error.t()}
@spec ancestor?(Path.t(), String.t(), String.t()) :: boolean()                         # merge-base --is-ancestor (exit 1 = false)
@spec diff_name_status(Path.t(), String.t(), String.t()) :: {:ok, [Si.Git.Porcelain.change()]}   # diff --name-status -z -M base head
@spec diff_unified0(Path.t(), String.t(), String.t(), [String.t()]) :: {:ok, String.t()}          # diff --unified=0 --no-color -M base head -- paths
@spec worktree_list(Path.t()) :: {:ok, [map()]}                                        # worktree list --porcelain -z
```
`update_ref/4` returns `{:error, :stale}` when git reports the old value does not match (stderr contains `cannot lock ref` or `is at ... but expected`).

**Porcelain parsers** (`Si.Git.Porcelain`, pure functions, NUL-separated input):
- `parse_status_v2/1` → `%{branch: %{oid: sha | nil, head: name | nil, upstream: name | nil}, entries: [%{kind: :changed | :renamed | :unmerged | :untracked | :ignored, xy: "M.", path: p, orig_path: p | nil}]}`.
- `parse_name_status/1` → `[%{status: "A" | "M" | "D" | "R" | "C" | "T", path: p, orig_path: p | nil, score: integer | nil}]`.
- `parse_worktree_list/1` → `[%{path, head, branch | nil, detached: boolean, locked: boolean, prunable: boolean}]`.

**Locks** (`Si.Git.Locks`, a GenServer child of the application):
```elixir
@spec with_lock(String.t(), (-> result), timeout()) :: result when result: term()   # key is the repo toplevel path; default timeout 60_000
```
FIFO per key. The holder is monitored; if it exits, the lock passes to the next waiter. On timeout the caller gets `exit({:timeout, {Si.Git.Locks, :with_lock, key}})`. Re-entrant calls from the same process for the same key are allowed (counter).

### Tests
- `cmd/3` success returns stdout without stderr noise (run `git status` in a repo where a `git` warning is forced, e.g. `-c core.safecrlf=warn`, or simply assert stdout equals expected output).
- `cmd/3` with an invalid subcommand returns `%Si.Git.Error{exit_status: 1 | 128}` with stderr text.
- Timeout: define a git alias in the temp repo `git config alias.hang '!sleep 5'` and call `cmd(repo, ["hang"], timeout: 200)` → `reason: :timeout` within ~1 s.
- `status/1` parses modified, added, deleted, renamed (with `git mv`), untracked files, including paths with spaces and non-ASCII characters (`"dir/ä b.txt"`).
- `update_ref/4`: create with `nil`, update with the correct old value, update with a wrong old value → `{:error, :stale}`.
- `ancestor?/3` true and false cases.
- `worktree_list/1` after `git worktree add` lists both worktrees.
- Locks: two processes with the same key never overlap (record timestamps into an Agent); the lock is released when the holder crashes; different keys run concurrently.
- Parser property test (StreamData): generate random file operations in a temp repo (create/modify/delete/rename up to 20 files with random names from a safe alphabet including spaces), then assert every path appears exactly once in `status/1` with the right kind.

### Acceptance criteria
1. No module other than `Si.Git` calls `System.cmd("git", ...)` or `MuonTrap.cmd` with git.
2. Tests pass; `bin/ci` passes.

**Expected result.**
- Every git call in Si goes through `Si.Git.cmd/3`, which runs git through MuonTrap with:
  - stderr captured in a temporary file;
  - hooks disabled;
  - `LC_ALL=C` and `GIT_TERMINAL_PROMPT=0`;
  - a timeout that kills the whole process tree.
- The parsers read NUL-separated output, including paths with spaces and non-ASCII characters.
- `update_ref/4` is compare-and-swap.
- `Si.Git.Locks` serializes work per repository in FIFO order.
