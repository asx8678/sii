### Goal
Every repository gets a `.si/repo.yml` describing how to format, build, lint, test, measure coverage and run mutation tests. Si detects a good starting profile and asks you to confirm it.

### Context
`05-schemas-and-config.md` §2 is the format and the Elixir defaults.

### Deliverables
- `protocol/repo_profile.schema.json`.
- `lib/si/repo_profile.ex` (`Si.RepoProfile` struct + load/validate), `lib/si/repo_profile/detect.ex` (`Si.RepoProfile.Detect`).
- Migration adding nothing new (columns `profile_hash`, `profile_confirmed_at` already exist from T01.02; add them now if they don't).
- CLI: `si repo init [path] [--yes] [--force]`, `si repo confirm [path]`.
- Tests with fixtures under `test/fixtures/repos/{ts_vitest,elixir_credo,plain}/` (only the files detection reads: `package.json`, `mix.exs`, `biome.json`, etc.).

### Specification
```elixir
defstruct [:language, :commands, :coverage_lcov_path, :mutation_report_path, :test_patterns,
           :risky_paths, :parallel_env, :ports_start, :ports_per_slot, :trust_project, :hash, :path]
@spec load(Path.t()) :: {:ok, t()} | {:error, :missing} | {:error, [String.t()]}   # repo toplevel
@spec command(t(), atom()) :: String.t() | nil
@spec confirmed?(Si.Repos.Repo.t()) :: boolean()      # stored hash == current file hash
@spec confirm(Si.Repos.Repo.t()) :: {:ok, Si.Repos.Repo.t()} | {:error, term()}   # stores hash + timestamp, event repo.profile_confirmed
```
Detection (`Si.RepoProfile.Detect.detect(toplevel) :: map()` returning the YAML-ready map):
- **TypeScript/JavaScript** (`package.json` exists): read `scripts` and `devDependencies`/`dependencies`.
  - `format`: `npm run format:check` if that script exists; else `npm run format -- --check` if the `format` script invokes prettier; else omitted.
  - `build`: `npm run typecheck` if present, else `npm run build` if present, else `npx tsc --noEmit` if `tsconfig.json` exists.
  - `lint`: `npm run lint -- {files}` if a `lint` script exists.
  - `test`: `npx vitest run {tests}` if `vitest` is a dependency; `npx jest {tests}` if `jest`; else `npm test`.
  - `test_all`: `npm test` if the script exists, else the `test` command without placeholders.
  - `coverage`: vitest → `npx vitest run --coverage --coverage.reporter=lcov {tests}` with `coverage.lcov_path: coverage/lcov.info`; jest → `npx jest --coverage --coverageReporters=lcov {tests}` with the same path.
  - `mutation`: if `@stryker-mutator/core` is a dependency → `npx stryker run --incremental --mutate {files}` with `mutation.report_path: reports/mutation/mutation.json`.
  - `tests.patterns`: `["**/*.test.ts", "**/*.spec.ts", "test/**/*.ts"]` (add `.tsx`/`.js` variants when such files exist).
- **Elixir** (`mix.exs` exists): the defaults from `05` §2; include `lint` only if `:credo` appears in `mix.exs`; include `coverage` only if `:lcov_ex` appears (lcov path `cover/lcov.info`).
- **Other**: `language: other`, empty `commands`.
- `risky_paths`: `[]` by default; add `"priv/repo/migrations/**"` for Elixir and `"migrations/**"` when such a directory exists.
- `parallel.ports`: `{start: 4100, per_slot: 10}`.

`si repo init [path]`: registers the repo if needed; if `.si/repo.yml` exists and `--force` is not given, print it and say `Profile exists; edit it or pass --force`; otherwise write it (with a first-line comment `# Generated by si repo init on <date>. Review and edit, then run si repo confirm.`), validate, print it, and with `--yes` confirm immediately. Exit 0.
`si repo confirm [path]`: validates and confirms; prints `Confirmed profile <short hash>`.

### Tests
- Detection for each fixture produces exactly the expected map (golden YAML files under `test/fixtures/repos/*/expected_repo.yml`).
- The written YAML validates against the schema.
- `confirm/1` stores the hash; editing the file makes `confirmed?/1` false.
- `load/1` on an invalid file returns errors with JSON pointers.
- CLI: `init` without `--force` does not overwrite; `--yes` confirms.

### Acceptance criteria
Tests pass; `bin/ci` passes; `si repo init --yes` on this repository (Elixir) produces the Elixir defaults.

**Expected result.**
- Detection reads only files and returns the exact profile map for TypeScript, Elixir and other repositories.
- Written profiles validate against `protocol/repo_profile.schema.json`.
- `confirm/1` stores the hash, and any later edit makes `confirmed?/1` false.
- `si repo init` never overwrites without `--force`.

**Checks**
1. `bin/si repo init . --yes && cat .si/repo.yml` (Verify).
   Expected: the Elixir defaults from `05-schemas-and-config.md` §2. `lint` is present because credo is a dependency; `coverage` is absent until T02.07. Then run `rm -rf .si && git status --porcelain`. Expected: no output. Si's own profile belongs to T05.10.

   Expected: the commands use those scripts. Without the scripts: the fallbacks from the Specification.
3. After `si repo confirm`, edit the file, then run `bin/si repo show <path>`.
   Expected: `unconfirmed`.
4. `shasum .si/repo.yml` before and after `bin/si repo init <path>` without `--force`.
   Expected: the same checksum, and the message `Profile exists; edit it or pass --force`.
5. An invalid profile, for example `language: cobol`.
   Expected: errors with JSON pointers such as `/language`.

**Redo if**
- Detection runs `npm`, `mix` or any other command. Rewrite it to read files only.
- The golden expected files were regenerated to match the output instead of the rules. Restore the goldens and fix detection.
