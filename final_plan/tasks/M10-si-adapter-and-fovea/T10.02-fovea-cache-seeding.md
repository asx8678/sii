### Goal
New worktrees start Fovea warm by copying the base checkout's fact cache, cutting the cold start (measured 2.81 s → 0.84 s on the Pi monorepo, output identical).

### Context
Measurements and facts (27 Sep 2026, pi-fovea 0.31.1): the cache is `os.tmpdir()/pi-fovea-<sha1(root)[0,16]>.json` (`cachePathFor` in `src/core/build.ts`), JSONL: a header `{"fovea": 16, "root", "rulesSha", "enrolled"}` then one line per file `{file, sha1, size, mtime, facts}`. Fovea reuses facts when a file's content hash matches, even when mtime differs, which is why seeding is safe. Eviction: caches older than 5 minutes are removed while the total exceeds 128 MiB; files larger than 64 MiB are never written.

### Deliverables
- `adapter/src/ops/fovea_seed.ts` (op `fovea.seed_cache`), `lib/si/fovea.ex` (`Si.Fovea`), a hook in `Si.Worktrees.create/2` for `:worker` and `:warm` worktrees (asynchronous); tests `adapter/test/fovea_seed.test.ts`, `test/si/fovea_seed_test.exs` (`@tag :pi`, `@tag :slow`).

### Specification
Op `fovea.seed_cache {from_root, to_root}`:
1. Guard: the installed pi-fovea version must be in the adapter's allowlist `{"0.31.1": 16}` (package version → expected header `fovea` value); otherwise return `{seeded: false, reason: "unsupported fovea version"}`.
2. `from = realpathSync(from_root)`, `to = realpathSync(to_root)`; import `cachePathFor` from `<node_modules>/pi-fovea/src/core/build.ts` by absolute file URL (the package `exports` map does not expose it) and compute both paths.
3. Source missing → `{seeded: false, reason: "no source cache"}`. Target exists → `{seeded: false, reason: "target exists"}`.
4. Read the source header; its `fovea` value must equal the allowlisted value; stream the file to `target + ".tmp-<pid>-<uuid>"` created with mode 0600, replacing only the header's `root` with `to`; `fsync` the file, then rename it into place.
5. Return `{seeded: true, bytes}`.
`Si.Fovea.seed(from_root, to_root) :: {:ok, map()} | {:error, term()}`; Si makes sure sessions and the adapter share `TMPDIR`.

### Tests
TS: header rewrite and atomic write with a fixture cache file; version guard; target exists. `@tag :pi @tag :slow`: clone `pi-fovea` into a temp dir as the base repo, run the toolchain's `fovea sketch <base> 900` once (cold, creates the cache), create a worker worktree through Si (which seeds), run `fovea sketch <worktree> 900`: assert it takes less than half of the cold time and its output equals a cold run's output after replacing the worktree path with a placeholder.
