### Goal
See every session and its live state in the cockpit, and stop Si-started sessions.

### Deliverables
- `SiWeb.SessionsLive` (list) and `SiWeb.SessionLive` (`/sessions/:id` detail), tests `test/si_web/live/sessions_live_test.exs`.

### Specification
- List: columns ID (link), role, state (colored badge: running = accent, idle = ok, settling = neutral, lost = error, stopped = muted), model, cwd (shortened with `~`), age. Updates live: subscribe to `"sessions"` and update rows on `{:session_state, id, state}`.
- Filter chips: All, Active (starting/idle/running/settling), Stopped, Lost.
- Detail: all row fields, the last 50 events (`Si.Events.list("session:<id>", ...)`) newest first, live-appended; a Stop button for `kind == "si"` sessions (calls `Si.Sessions.stop/2`, then shows the new state).
- Empty state text unchanged from T00.10.

### Tests
LiveView tests: list renders existing sessions; a broadcast state change updates the badge without reload; Stop button calls the API (use the fake Pi session from T03.07 helpers).

### Acceptance criteria
Tests pass; `bin/ci` passes.

### Verify
```bash
mix test test/si_web/live/sessions_live_test.exs
```
