### Goal
Start, find, message and stop Pi sessions through one API, supervised per session, with a CLI.

### Context
`01-architecture.md` §3 (supervision tree), `04-protocols.md` §1.1 (launch command and env).

### Deliverables

- CLI `lib/si/cli/commands/session.ex`.

### Specification
```elixir
@spec start(keyword()) :: {:ok, String.t()} | {:error, term()}
#   opts: role (required), cwd (required unless worktree), worktree, repo, profile (default by role), model ("provider/model"; default settings models.<role>),
#         thinking, prompt (initial), env ([{k, v}]), run_id, task_id, review_thread_id, extra_extensions, provider/model override (tests), trust_project
@spec stop(String.t(), term()) :: :ok | {:error, :not_found}
@spec prompt(String.t(), String.t(), keyword()) :: :ok | {:error, term()}
@spec abort(String.t()) :: :ok | {:error, term()}
@spec request(String.t(), String.t(), map(), timeout()) :: {:ok, term()} | {:error, term()}
@spec await_state(String.t(), atom() | [atom()], timeout()) :: :ok | {:error, :timeout | term()}
@spec last_assistant_text(String.t()) :: {:ok, String.t()} | {:error, term()}
@spec get(String.t()) :: Si.Sessions.Session.t() | nil
@spec list(keyword()) :: [Si.Sessions.Session.t()]        # filters: state, role, repo_id, kind
@spec whereis(String.t()) :: pid() | nil                   # Registry {:session, id}
```
`start/1`:
1. `Si.Toolchains.current/0`; `Si.Profiles.ensure!(profile)`.
2. Parse the model string `"provider/model"` (split on the first `/`).
3. New `ses_` id (valid as a Pi session id: letters, digits, `_`); stderr log `Si.Paths.session_stderr_log(id)`.
4. Spec: executable = toolchain `pi_bin`; args = `["--mode", "rpc", "--session-dir", Si.Paths.sessions_dir(), "--session-id", id, "--provider", p, "--model", m] ++ thinking_args ++ Si.Profiles.launch_args(profile, toolchain, opts)`. `--session-id` creates the session if it does not exist and reopens it otherwise (Pi `docs/cli.md`), so restarting a session is the same command; `--session <path>` would only open an existing session. Env = `PI_CODING_AGENT_DIR`, `PI_CACHE_RETENTION` (from settings `cache.retention`, default `long`), `SI_SESSION_ID`, `SI_ROLE`, `SI_RUN_ID`, `SI_TASK_ID` (when set), `SI_BRIDGE_URL` and `SI_BRIDGE_TOKEN` (when the bridge exists, T04.02), plus `opts[:env]`.
5. Insert the row (`kind: "si"`, `state: "starting"`, `versions` from the toolchain) and event `session.started`; start `SessionSup` under the DynamicSupervisor; register `{:session, id}`.
6. Wait until the session is `:idle` (or failed) before returning; the controller has stored the session file path from `get_state`. Send `prompt` if given.

CLI:
- `si session list [--all]` → table `ID · ROLE · STATE · MODEL · CWD · AGE` (running/idle sessions by default).
- `si session start --role <role> [--cwd PATH] [--model provider/model] [--prompt TEXT] [--extension PATH]...` → prints the id. Each `--extension` is passed to Pi as an extra `-e` (`extra_extensions`).
- `si session prompt <id> <text> [--wait]` → with `--wait`, waits for idle and prints the last assistant text.
- `si session stop <id>`; `si session show <id>` (row fields + last 20 events).
