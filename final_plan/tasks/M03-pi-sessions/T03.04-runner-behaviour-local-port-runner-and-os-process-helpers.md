### Goal
Start and stop OS processes that talk over stdin/stdout (Pi RPC), with stderr to a log file and reliable cleanup of the process and its descendants.

### Context
`01-architecture.md` §4 (runner decision: plain Erlang Port, not MuonTrap, because MuonTrap's wrapper does not forward stdin; Pi exits in an orderly way on stdin EOF).

### Deliverables
- `lib/si/runner.ex` (behaviour + `Si.Runner.Spec` struct), `lib/si/runner/local.ex` (`Si.Runner.Local`), `lib/si/runner/local/port_owner.ex` (GenServer), `lib/si/os_process.ex` (`Si.OsProcess`).
- Tests `test/si/runner/local_test.exs`, `test/si/os_process_test.exs`.

### Specification
```elixir
defmodule Si.Runner do
  @type handle :: %{ref: reference(), impl: module(), pid: pid()}
  @callback start(Si.Runner.Spec.t(), owner :: pid()) :: {:ok, handle} | {:error, term()}
  @callback send_data(handle, iodata()) :: :ok | {:error, :closed}
  @callback stop(handle, :graceful | :kill) :: :ok
  @callback os_pid(handle) :: non_neg_integer() | nil
end
# Spec: %Si.Runner.Spec{id, executable, args, env: [{String.t(), String.t()}], cwd, stderr_log}
```
Owner messages: `{:runner_data, ref, binary}` and `{:runner_exit, ref, exit_status | :closed}`.

`Si.Runner.Local`:
- `start/2` starts a `PortOwner` (linked to the caller) which opens:
  `Port.open({:spawn_executable, "/bin/sh"}, [:binary, :exit_status, :use_stdio, :hide, args: ["-c", "exec \"$0\" \"$@\" 2>>\"$SI_STDERR_LOG\"", executable | args], env: env ++ [{"SI_STDERR_LOG", stderr_log}], cd: cwd])`.
  With `exec`, the OS pid of the port is the executable's pid; read it with `Port.info(port, :os_pid)` and keep it.
- Data from the port is forwarded to the owner; `exit_status` is forwarded and the PortOwner stops normally.
- `stop(handle, :graceful)`: `Port.close/1` (stdin EOF); poll `Si.OsProcess.alive?/1` every 100 ms for 5 s; then `Si.OsProcess.terminate_tree(os_pid, :term)`; after 5 s more, `:kill`. Always also kill remaining descendants collected **before** closing (`descendants/1`), because they may be re-parented. Then notify the owner `{:runner_exit, ref, :closed}`.
- `stop(handle, :kill)`: descendants + pid get SIGKILL immediately.

`Si.OsProcess` (via `System.cmd`, no shell):
```elixir
@spec alive?(non_neg_integer()) :: boolean()                    # kill -0
@spec descendants(non_neg_integer()) :: [non_neg_integer()]      # recursive pgrep -P
@spec signal(non_neg_integer(), :term | :kill) :: :ok
@spec terminate_tree(non_neg_integer(), :term | :kill) :: :ok    # descendants first (deepest first), then the pid
@spec rss_kb(non_neg_integer()) :: non_neg_integer() | nil       # ps -o rss= -p pid
```

### Tests
- `cat` round trip: send `"hello\n"`, receive `"hello\n"`.
- Graceful stop of `cat` exits via EOF (no signals needed: assert `alive?` false within 1 s).
- A process ignoring EOF and SIGTERM (`sh -c 'trap "" TERM; while :; do sleep 0.2; done'`) is killed within 11 s.
- Descendants: `sh -c 'sleep 101 & exec cat'`; after `stop/2`, no process with command `sleep 101` remains (use a unique number).
- stderr: a command writing to stderr ends up in the log file, not in the data messages.
- Exit status is forwarded when the process exits by itself (`sh -c 'exit 3'` → `{:runner_exit, ref, 3}`).
- `rss_kb/1` returns a positive number for the test process's `cat`.

### Acceptance criteria
Tests pass; `bin/ci` passes; no stray processes after the test suite (`pgrep -f 'sleep 101'` empty).

**Expected result.**
- `Si.Runner.Local` runs an executable under a plain Erlang Port. It sends stdout to the owner, appends stderr to a log file, and forwards the exit status.
- It stops gracefully through stdin EOF, and escalates to SIGTERM and then SIGKILL, collecting descendants before closing.
- `Si.OsProcess` provides `alive?`, `descendants`, `signal`, `terminate_tree` and `rss_kb`.

**Checks**
1. `pgrep -f 'sleep 101'` after the tests (Verify).
   Expected: no process.
2. Stop timings from the tests.
   Expected: `cat` exits within 1 s of EOF. The process that ignores TERM is gone within 11 s.
3. A command that writes `err` to stderr and `out` to stdout.
   Expected: `out` arrives as a data message; `err` is only in the log file.
4. Kill the process that owns the runner.
   Expected: the OS process is gone within 11 s (it is linked to the caller).
5. `grep -n 'MuonTrap' lib/si/runner* -r`.
   Expected: no output.

**Redo if**
- MuonTrap is used here. It does not forward stdin; rewrite with a plain Port, as specified.
- Descendants are collected after the Port is closed. Rewrite the stop sequence to collect them before closing.
