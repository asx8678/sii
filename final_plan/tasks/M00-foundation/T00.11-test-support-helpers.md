### Goal
Shared helpers for temporary homes, temporary git repositories and asynchronous assertions, used by almost every later test.

### Deliverables
- `test/support/si_test/home.ex` (`Si.Test.Home`), `test/support/si_test/git.ex` (`Si.Test.Git`), `test/support/si_test/eventually.ex` (`Si.Test.Eventually`).
- `test/support/si_test/case.ex` (`Si.Test.Case`: `use ExUnit.CaseTemplate` that imports the helpers).
- `test/si_test/helpers_test.exs`.
- `mix.exs`: `elixirc_paths(:test)` includes `test/support` (the generator already does).

### Specification
`Si.Test.Home`:
```elixir
@spec tmp_home!(ExUnit.Callbacks.context()) :: Path.t()   # creates a unique dir, puts Application env :si, :home, registers on_exit cleanup + restore
```
Use it only in tests that must not share the global test home; tests that touch `Application` env are `async: false`.

`Si.Test.Git`:
```elixir
@spec init_repo!(keyword()) :: Path.t()      # opts: files: %{path => content}, branch: "main"; runs git init -b main, sets local user.name/user.email, commits files (or a README) → returns the path
@spec write!(Path.t(), String.t(), iodata()) :: :ok
@spec commit!(Path.t(), String.t()) :: String.t()            # git add -A && git commit -m; returns the new HEAD sha
@spec branch!(Path.t(), String.t()) :: :ok                    # git checkout -b
@spec checkout!(Path.t(), String.t()) :: :ok
@spec head!(Path.t()) :: String.t()
@spec many_files!(Path.t(), pos_integer()) :: :ok             # writes n files in nested dirs (for performance tests) and commits
@spec git!(Path.t(), [String.t()]) :: String.t()              # runs git with GIT_CONFIG_GLOBAL=/dev/null, GIT_CONFIG_NOSYSTEM=1, HOME=<tmp> and XDG_CONFIG_HOME=<tmp>, so no global or system git config interferes
```
All repos live under `System.tmp_dir!()/si_test_repos/<unique>` and are deleted `on_exit` when created through `Si.Test.Case` setup helpers.

`Si.Test.Eventually`:
```elixir
@spec assert_eventually((-> boolean()), pos_integer(), pos_integer()) :: :ok   # timeout_ms \\ 2_000, interval_ms \\ 20; flunk with a clear message
```

### Tests
- `init_repo!` creates a repo with one commit on `main`.
- `commit!` returns a new sha different from the previous head.
- `many_files!(repo, 50)` creates 50 tracked files.
- `assert_eventually` passes when the condition becomes true and fails (with ExUnit.AssertionError) after the timeout otherwise.
- With `GIT_CONFIG_GLOBAL` pointing to a file that sets `user.name = WRONG` and `commit.gpgsign = true`, `init_repo!/1` and `commit!/2` still work and the commits carry the helper's local identity.

### Acceptance criteria
Tests pass; `bin/ci` passes; helpers never read the developer's global git config.

### Verify
```bash
mix test test/si_test/helpers_test.exs
```

**Expected result.**
- `Si.Test.Home`, `Si.Test.Git`, `Si.Test.Eventually` and `Si.Test.Case` behave as specified.
- Git helpers never read the developer's git configuration: `git!/2` sets `GIT_CONFIG_GLOBAL=/dev/null`, `GIT_CONFIG_NOSYSTEM=1`, a temporary `HOME` and `XDG_CONFIG_HOME`.
- Temporary repositories are deleted after the tests that created them.

**Checks**
1. Write a hostile config to `"$TMPDIR/hostile.gitconfig"` (`[user] name = WRONG` and `[commit] gpgsign = true`). Run `GIT_CONFIG_GLOBAL="$TMPDIR/hostile.gitconfig" mix test test/si_test/helpers_test.exs`.
   Expected: the tests pass, and commits made by the helpers carry the helper's local user (a test asserts the author).
2. `ls "$TMPDIR/si_test_repos" 2>/dev/null | wc -l`, before and after `mix test`.
   Expected: no growth.
3. A failing `assert_eventually` (from the test).
   Expected: the failure message names the timeout and the interval.

**Redo if**
- A helper runs git through `System.cmd("git", …)` without the isolated environment. Route it through `git!/2`.
- A helper depends on the current working directory. Rewrite it with explicit paths.
