### Goal
Generate sortable, prefixed identifiers for every entity.

### Context
`03-data-model.md` §1 lists every allowed prefix.

### Deliverables
- `lib/si/id.ex` (`Si.Id`), `test/si/id_test.exs`.

### Specification
```elixir
@prefixes ~w(evt repo wt snp cks chk tc ses mc trn tcl fx ctl slot rth rev fnd apr inb tsk att scp mq dlv run stp plr sig int lda flr les etk evr evx can)
@spec generate(String.t()) :: String.t()        # raises ArgumentError for unknown prefixes
@spec prefix(String.t()) :: String.t() | nil
@spec valid?(String.t()) :: boolean()
@spec valid?(String.t(), String.t()) :: boolean()   # also checks the prefix
@spec timestamp(String.t()) :: DateTime.t()          # decoded from the ULID time part (ms precision)
```
- ULID: 48-bit Unix time in milliseconds (`System.system_time(:millisecond)`) + 80 random bits (`:crypto.strong_rand_bytes(10)`), encoded as 26 characters of Crockford base32 (alphabet `0123456789abcdefghjkmnpqrstvwxyz`, lowercase), time first.
- Format: `<prefix>_<26 chars>`; regex `~r/^[a-z]+_[0-9a-hjkmnp-tv-z]{26}$/`.
- Implement encoding with binary pattern matching over 5-bit groups (`<<x::5, rest::bitstring>>` on the 130-bit value padded as needed; ULID uses 128 bits → the first character encodes only 3 bits, so prepend 2 zero bits: `<<0::2, time::48, rand::80>>` is 130 bits = 26 × 5).

### Tests
- Format regex for each prefix.
- Unknown prefix raises.
- `timestamp/1` is within 5 ms of `DateTime.utc_now/0` for a fresh id.
- Property (StreamData): for two ids generated in sequence with a 2 ms sleep between them, `a < b` as strings.
- 100,000 generated ids are unique.
- `valid?/2` false for a wrong prefix, wrong length, or uppercase characters.

### Acceptance criteria
Tests pass; `bin/ci` passes.

### Verify
```bash
mix test test/si/id_test.exs
mix run --no-start -e 'IO.puts Si.Id.generate("ses")'    # e.g. ses_01j9z3x4... (26 chars after the underscore)
```

**Expected result.** `Si.Id` generates identifiers of the form `<prefix>_<26 characters>`: time-ordered ULIDs in lowercase Crockford base32, allowed only for the prefixes listed in `03-data-model.md` §1.

**Checks**
1. Compare the prefixes in `03-data-model.md` §1 with `@prefixes`.
   Expected: the same set, with nothing missing and nothing extra.
2. Run `mix run --no-start -e 'for _ <- 1..5 do IO.puts(Si.Id.generate("tsk")); Process.sleep(2) end' | tee "$TMPDIR/ids" | sort -c && grep -cE '^tsk_[0-9a-hjkmnp-tv-z]{26}$' "$TMPDIR/ids"`.
   Expected: `sort -c` reports nothing, and the count is `5`.
3. `mix run --no-start -e 'IO.inspect Si.Id.timestamp(Si.Id.generate("evt"))'`.
   Expected: the current UTC time, to the millisecond.
4. `mix run --no-start -e '{us, _} = :timer.tc(fn -> for _ <- 1..100_000, do: Si.Id.generate("evt") end); IO.puts(us)'`.
   Expected: less than `2000000` (100,000 ids in under 2 s).

**Redo if**
- The alphabet contains `i`, `l`, `o`, `u` or uppercase letters. Rewrite the encoder with the exact alphabet.
- Encoding uses integer division loops instead of 5-bit binary pattern matching. Rewrite it as specified.
- The random part comes from `:rand`. Use `:crypto.strong_rand_bytes/1`.
