### Goal
The LiveView skeleton every later page plugs into: layout, navigation, empty states, and a health endpoint.

### Deliverables
- `lib/si_web/components/layouts.ex` updates: app layout with a left navigation: Runs, Tasks, Reviews, Inbox, Sessions, Analytics, Settings.
- LiveViews `SiWeb.RunsLive`, `TasksLive`, `ReviewsLive`, `InboxLive`, `SessionsLive`, `AnalyticsLive`, `SettingsLive` (each `mount/3` + `render/1` with an empty state).
- Routes: `/` redirects to `/reviews`; `/runs`, `/tasks`, `/reviews`, `/inbox`, `/sessions`, `/analytics`, `/settings`.
- `SiWeb.HealthController` at `GET /health`.
- Tests in `test/si_web/live/navigation_test.exs`, `test/si_web/controllers/health_controller_test.exs`.

### Specification
- Use Phoenix 1.8's Tailwind + daisyUI setup from the generator; support light and dark themes through daisyUI's theme tokens (`prefers-color-scheme`), no hard-coded colors in templates.
- Empty-state texts (exact): Reviews: `No reviews yet. Run si review in a repository.`; Tasks: `No tasks yet. Add one with si task add.`; Runs: `No runs yet.`; Inbox: `Nothing is waiting for you.`; Sessions: `No sessions yet.`; Analytics: `No data yet.`; Settings: shows `Si.Settings.all()` as read-only formatted YAML-like text (use `Jason.encode!(map, pretty: true)` inside a `<pre>`).
- The active nav item is highlighted (`aria-current="page"`).
- `/health` returns JSON `{"status": "ok", "node": "<node name>", "version": "<si version>", "db": "ok" | "error"}`; `db` comes from `Ecto.Adapters.SQL.query(Si.Repo, "SELECT 1")`. HTTP 200 when db is ok, 503 otherwise.

### Tests
- Each route renders and contains its empty-state text and the navigation with 7 links.
- `/` redirects to `/reviews`.
- `/health` returns 200 with the four keys.

### Acceptance criteria
Tests pass; `bin/ci` passes; pages render in both themes (manual check in a browser).

### Verify
```bash
mix test test/si_web
curl -s http://127.0.0.1:4040/health     # with the server running: {"status":"ok",...}
```

**Expected result.**
- One layout with seven navigation links; the active link has `aria-current="page"`.
- Seven LiveViews, each showing its exact empty-state text.
- `/` redirects to `/reviews`.
- `/health` returns JSON with four keys: 200 when the database answers, 503 when it does not.
- Colors come only from daisyUI theme tokens.

**Checks**

2. `curl -s http://127.0.0.1:4040/health | jq -r 'keys|join(",")'`.
   Expected: `db,node,status,version`.
3. `grep -rnF` each empty-state text from the Specification in `lib/si_web`.
   Expected: each text is found once, exactly as written.
4. `grep -rnE '#[0-9a-fA-F]{3,6}\b|rgb\(' lib/si_web`.
   Expected: no output.
5. A test covers the 503 case by making the database query fail.
   Expected: the response is `503` with `"db": "error"`. Add the test if it is missing.
6. The visual check of both themes.
   Expected: the owner confirms it, or the completion note says it was not checked visually.
