### Goal
One helper that wraps work in both a `:telemetry` span and an OpenTelemetry span, so later tasks get tracing for free.

### Deliverables
`lib/si/trace.ex` (`Si.Trace`), `lib/si/telemetry.ex` (`Si.Telemetry`, supervisor child that attaches handlers), `test/si/trace_test.exs`.

### Specification
```elixir
@spec span([atom()], map(), (-> result)) :: result when result: term()
```
- Emits `[:si | name] ++ [:start]`, `[:stop]` or `[:exception]` via `:telemetry.span/3` with the metadata map.
- Wraps the function in `OpenTelemetry.Tracer.with_span("si." <> Enum.join(name, "."), %{attributes: attrs})` where `attrs` are the metadata entries whose values are strings, numbers or booleans.
- Re-raises exceptions after recording them (`OpenTelemetry.Span.record_exception/2`).
- `Si.Telemetry` attaches a debug-level logger handler for `[:si, :_, :stop]` events that logs name and duration in ms. It is started after `Si.Settings`.

### Tests
- A handler attached in the test receives start and stop events with the metadata and a `:duration` measurement.
- An exception inside the function emits `:exception` and is re-raised.
- The return value is passed through.

### Acceptance criteria
Tests pass; `bin/ci` passes; with the `:none` exporter no network activity happens.

### Verify

**Expected result.**
- `Si.Trace.span/3` wraps work in both a telemetry span and an OpenTelemetry span.
- It passes the return value through, and records and re-raises exceptions with their original stacktrace.
- `Si.Telemetry` logs stop events at debug level.
- Nothing is exported.

**Checks**
1. `SI_HOME=$(mktemp -d) mix run -e 'IO.inspect Si.Trace.span([:demo], %{a: "b", n: 1, pid: self()}, fn -> :ok end)'`.
   Expected: `:ok`, with no crash from the non-scalar `pid` metadata (it is left out of the attributes).
2. A test raises inside `span/3`.
   Expected: the re-raised exception's stacktrace points at the raising line, not at `Si.Trace`.
3. `grep -n 'Si.Telemetry' lib/si/application.ex`.
   Expected: it appears after `Si.Settings` in the children list.
4. `grep -rn 'exporter' config`.
   Expected: only `traces_exporter: :none`.

**Redo if**
- Non-scalar metadata reaches the OpenTelemetry attributes. Filter them as specified.
- An exception is swallowed, or re-raised without `__STACKTRACE__`. Rewrite with `reraise`.
