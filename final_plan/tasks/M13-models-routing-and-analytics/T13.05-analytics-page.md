### Goal
Answer "where did the time and money go" in the cockpit.

### Deliverables
`lib/si/analytics.ex` (query functions), `SiWeb.AnalyticsLive` with inline SVG chart components (bar and line) styled with theme tokens; tests of the queries and a render test.

### Specification
Views (7 or 30 days, filter by repo):
- Cost by role and by model (stacked bars per day).
- Cache savings per provider: `cached tokens × (input price − cached price)`.
- Failure rates: tool errors per 100 calls by tool; `fabric_exec` failures per 1,000 by model and stage.
- Time breakdown per run: model latency, tools, waiting for slots (`wait_ms`), checks, reviews (from task transitions and check durations).
- Slot waits by pool (p50/p95).
Charts: every mark and label derived from one scale; empty states when there is no data.

### Tests
Each query on fixtures (exact numbers); LiveView renders with and without data.

### Acceptance criteria
Tests pass; `bin/ci` passes.

### Verify
```bash
mix test test/si/analytics_test.exs test/si_web/live/analytics_live_test.exs
```
