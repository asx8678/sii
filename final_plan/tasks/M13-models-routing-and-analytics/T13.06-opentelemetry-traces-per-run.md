### Goal
One trace per run with nested spans for steps, tasks, rounds, turns, tool calls, checks and reviews, exportable to any OTLP backend.

### Deliverables
Span instrumentation through `Si.Trace` with parent context stored on run, task and review processes (`OpenTelemetry.Ctx` propagation); settings `telemetry.otlp_endpoint` (null = no export); dependency `opentelemetry_exporter ~> 1.11`; tests with a test exporter.

### Specification
Span names: `si.run`, `si.step`, `si.task`, `si.round`, `si.check`, `si.review`, `si.session.turn`, `si.tool` (turn and tool spans are created from bridge events with explicit start/end timestamps). Attributes: ids, model, verdict, check status, cost. When `otlp_endpoint` is set, configure the exporter at boot.

### Tests
With the pid exporter (`otel_exporter_pid`) or an in-memory exporter, a faux run produces the expected span tree (parent/child relations and names).

### Acceptance criteria
Tests pass; `bin/ci` passes.
